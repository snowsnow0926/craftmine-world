# 第一次自主创作：简明操作指南

日期：2026-09-13。适用于本轮自主创作开发版的 PI Desktop 界面。
已交付的 preview.21 尚未包含这里新增的“直接使用”按钮；其游玩和世界模板功能仍可使用。

1. **打开世界。** 从世界入口打开已有世界，或选择“新建世界”。先等世界准备完成，再打开侧边栏的“素材与作品库”。
2. **选择现成素材。** 在本地库搜索并查看详情，确认素材名称和版本。带跟随行为的博美组件与只有外观的博美模型是不同素材。
3. **准备加入。** 对支持的组件，在“直接使用”中选择“检查并准备加入”。默认使用素材原来的位置；支持调整坐标时，可展开输入 X、Y、Z，单位为米，Y 表示高度。无需连接 AI。
4. **确认加入并试玩。** 在上方“素材操作”看到检查通过后，选择“加入当前世界”。完成后关闭素材库，查看实际位置并试玩。检查世界兼容性不等于已经证明摆放美观或没有任何重叠。
5. **继续修改。** 界面明确支持编辑的对象，可以使用现有编辑、检查应用和撤销功能。任意模型不一定都有尺寸、颜色等可编辑参数。需要自然语言修改或新玩法时，继续使用原有 AI 加入／修改入口，并核对自己选择的 Agent、模型和思考强度。
6. **保存与重开。** 使用现有保存退出流程，确认成功后完全关闭应用，再打开原世界，检查内容和游玩进度是否保留。
7. **分享作品。** 在素材库的“保存世界模板”中保存当前世界；需要保留进度时明确勾选该选项。到“我的模板”导出 ZIP，交给有完整客户端的朋友导入并创建独立世界。模板 ZIP 不是独立游戏 EXE。

关闭素材面板不会取消操作；重新打开可查看进度。彻底重开应用后，界面会向主进程重新核对保存的操作，不会自动重新安装或自动确认加入。需要停止时，使用该条操作上的“取消本次操作”。

失败时先看“检查原因”。原来的正式世界仍保留；已经写入的草稿可能保留，界面会明确说明。重复提交响应不明的请求时，使用“重试本次准备”，避免重新创建一条同样的操作。

世界模板用于创建独立世界，原始图片／模型等资源需要先组装为可放置对象。如果直接使用入口说明不支持，可保留原始需求交给 AI 处理。
