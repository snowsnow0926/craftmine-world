# Alpha 0.8：自己的素材，继续运行的玩法

2026-09-08，M4 素材阶段验收完成。个人创作 Alpha 的整体目标仍在进行，下一阶段 M5 是通过自然语言完成采集、制作、战斗与任务的完整可复用世界。

## 使用变化

1. 打开“素材与记忆”，导入本地 PNG、JPEG 或静态 GLB。系统实际解码和绘制后保存，可独立预览。
2. 选择世界里的对象，在素材卡片选择版本，点击“用于所选对象”。也可以描述“把这扇门换成我导入的某某门面”。助手读取真实素材名字、尺寸、身份和版本。
3. 候选可以先比较差异和试玩，再应用。换外观保留对象 ID、原几何碰撞、源码和兼容进度。恢复原几何也走候选流程。
4. 导入同一素材的新版本后，原实例继续引用旧版。可以主动换新版或回退。素材文件缺失时，可重新导入原素材包恢复。
5. “导出存档”携带当前世界、源码、最新进度及实际引用的素材文件。记忆库里的单独对象和完整创作也会携带所需素材，能在另一兼容项目重新检查、安装和继续使用。

完整存档不包含整个历史模块库、对话或项目长期约定。导入完整存档恢复文件中的进度；复用创作产生独立身份及初始状态；切换已有实例版本保留兼容状态。三种操作的目的不同。

## 当前范围

- 单文件最多 8 MiB；图片单边最多 2,048 像素。GLB 支持静态网格、节点变换、内嵌基础颜色贴图、顶点颜色和透明材质。动画、蒙皮、压缩与不支持的必需扩展明确拒绝，需要预先转换。
- 世界最多 16 个不同素材版本、32 MiB 原始文件、200,000 个三角形、256 次网格绘制、16M 纹理像素。完整作品包最多 48 MiB。
- 素材世界需要 WebGL。光照是简化模型，透明网格按对象距离排序，尚不支持完整 PBR、动画播放或所有交叠三角面的精确透明排序。
- 默认外观等比例适配原对象范围。碰撞与互动范围由原 parts 几何定义，不自动生成精确网格碰撞。源码的位移、显隐、颜色及摧毁状态仍作用于同一对象。
