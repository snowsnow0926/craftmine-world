## 全新用户目录：五次实际启动全部通过

1. 用原 PI Desktop 新建世界表单创建世界，从真实素材库直接加入白色博美，完成正常检查并采用。
2. 在第一条创作回合之前正常退出并冷启动。仍恢复到同一个真实会话，重新读取后消息数为 **0**，原有创作编辑器可用。
3. 通过“在此放置”创建普通树木，再通过现有编辑器改为 `1.25 × 1.25 × 1.25`、颜色 `#88bb44`；两次正常检查与采用均通过。保存并冷启动重开，对象及进度保持。
4. 用普通表单勾选保留进度、保存世界模板并导出 ZIP；在第二个空白用户目录中仅导入该 ZIP，新建不同世界并实际移动游玩。
5. 再次保存并冷启动重开，仍保留同一博美实例和树木属性，背包及奖励记录保持。

五次启动都正常以代码 **0** 退出；窗口违规、页面错误和退出清理失败列表均为空。按照持久化消息所属的真实回合读取指标，已观测模型调用为 **0**。直接素材操作没有伪造作者回合。

博美的正式组件实体为 `ins-b476c7d25ee75f2b2196c629-e0`，与安装回执的根实例 ID 明确区分。树木属于现有编辑器支持的普通对象；本验收不声称任意导入 GLB 已支持直接改色。

发布前与导入游玩后均根据真实树木边界、博美位置和玩家位置执行正常移动与转向，再截取原生画面。已目视确认完整树木与白色博美同时可见，没有生成替代图片。PI 工作台的独立截图显示检查通过和编辑完成，原有复用面板不再出现 `PERMISSION_DENIED`。
