## 独立真实引擎反证

使用 Godot 4.7.2 Compatibility 导入同一 GLB，逐个读取每个实际 MeshInstance 的顶点；每个 clip 采全部原始关键帧、相邻关键帧中点及 1/240 秒中间时刻。普通犬 3987648 次顶点采样，博美 4486104 次。采样轴范围分别为 [-0.195080906,0,-0.678050339]..[0.195080906,0.758147895,0.720000029] 与 [-0.181500003,0,-0.345766783]..[0.181500003,0.467997968,0.276572675]，上一版文档曾错误声称均落在连续解析界内；旧界没有包含 idle 采样的 Y=0 且不是独立逐轴证明。本次修正改用独立 GLB 解析模块重算保守逐轴界，并逐项断言所有采样轴范围落在界内；采样仍只作反证，不替代连续推导。

## 对碰撞合同的影响

宠物根 forward=-Z；根仅绕 Y 时，局部 X/Z 盒体会随 yaw 旋转，门洞不能只比较固定 X 宽。直门移动应使用实际 BoxShape3D 与门柱碰撞；L 通道转身应验证旋转扫掠，转角空间不足时停下并保留位置。禁止瞬移、缩碰撞、AABB 命中冒充物理通过。形状恢复仍需实际 shape query 和身份/进度完整校验。

机器证据：D:\cm-pet-corridor-impl-0912\test-results\canine-axis-envelope-Ehjkhv\report.json。

独立重算模块：`tests/canine-axis-envelope-independent.mjs`，直接解析 GLB JSON/BIN accessor 与节点父链，按每个网格节点的实际平移和顶点三维长度建立连续旋转球形包络。该包络比逐轴精确极值更保守，但不会把径向半径误称为门洞 X 宽；实际根 yaw 的世界投影仍须按旋转后的 OBB/扫掠处理。

## 独立解析结果

`tests/canine-axis-envelope-independent.mjs` 直接解析最终 GLB 的 JSON/BIN accessor 和七个实际网格节点，不读取 manifest 的轴界。为覆盖所有声明刚体旋转，它对每个顶点围绕其实际节点父链平移建立连续三维球形包络；该结果是可证明的保守界，不是径向半径冒充门洞宽。真实采样逐轴范围均通过断言。机器结果：`test-results/canine-axis-envelope-independent.json`。

- dog：连续保守 min `[-0.448485354,-0.048485354,-0.678057672]`，max `[0.448485354,0.878057672,0.752699644]`；实际采样 min `[-0.195080906,0,-0.678050339]`，max `[0.195080906,0.758147895,0.720000029]`。
- pomeranian-white：连续保守 min `[-0.255346549,-0.009520476,-0.426003030]`，max `[0.255346549,0.576003030,0.429711906]`；实际采样 min `[-0.181500003,0,-0.345766783]`，max `[0.181500003,0.467997968,0.276572675]`。

球形包络明显比真实姿态宽，适合安全预检，不适合直接当作可通行门宽；窄通道实现仍应使用局部 Box 的实际旋转扫掠测试。
