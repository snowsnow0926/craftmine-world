# 宠物连续转向的变换稳定性修复

城市实测发现，宠物长时间转弯后保存会报 PET_RESTORE_TRANSFORM_UNSUPPORTED。
已确认白色博美和通用宠物的 v3 都继承了同一实现：
global_rotation.y = value 在反复设置欧拉角时保留并累积浮点缩放误差。

新增两个 v4 包，只将这行改成 global_basis = Basis(Vector3.UP, value)，
保留原有朝向缓存。状态格式、身份、位置、名字、外观、跟随开关、抚摸次数、
保存范围配置、碰撞和恢复校验均不改变，也不增加寻路能力。

真实 Godot 4.7.2 的独立无窗口 CPU 测试在 60 Hz 下运行 3000 次转向：

| 版本 | 实际运行 | 最大单位缩放误差 | 原恢复校验 |
| --- | --- | --- | --- |
| v3 博美与通用宠物 | 50.004 秒 | 0.0000369549 | 两者均拒绝变换 |
| v4 博美与通用宠物 | 50.005 秒 | 0.0000000596 | 两者均通过 |

之后用新进程读取保存文件，完整 JSON 状态保持一致。非法子碰撞体缩放和超出
城市范围的位置仍被拒绝。三段 CPU 测试共 33 项检查通过；包与库回归 12 项通过。
该测试隔离朝向问题，不证明宠物能绕过城市障碍；导航体验由主流程另行验收。

素材库新增 v4，默认最新版本查询可找到它。旧博美 v1/v2/v3 与通用宠物
v2/v3 的全部已构建 ZIP 哈希保持一致，视觉文件也未改变。固定组合配方仍保留
原版本引用；旧世界或自定义继承脚本需要正常的源码更新、检查和应用，不能因
素材库出现 v4 就声称它们已经修好。
