# M3.2：候选差异与独立试玩

2026-09-08。这是下一版本的开发切片；个人服务仍运行 Alpha 0.6，M3.3 长期上下文验收完成后再集中更新。

## 已实现

候选就绪后可打开“查看变化与预览”。按稳定 ID 区分对象、内置系统和代码玩法的新增、修改、移除；展示名称、位置、外观与碰撞、参数、源码、状态格式、依赖与世界设置的真实变化。字段表显示当前值和候选值，较长内容可展开查看完整定义。源码以连续变化块比较，保留全部变化行，不宣称为最少行编辑算法。

画面中的“当前世界”和“候选世界”都是独立副本。打开时冻结原世界并读取最新进度；副本可以实际运行代码、互动和走动，切换版本或重置重新从原进度建立副本。普通候选沿用观察位置；完整存档候选明确使用文件中的进度。关闭后释放副本并恢复原世界；副本状态不进入自动保存、历史、记忆库或导出。

选中差异可以定位查看对象。移除的对象在当前版本副本中查看，代码规则定位到其关联对象。可将原世界已有对象选为下一次对话的修改范围。对象卡片显示选中状态。

应用仍通过原有事务：读取原世界的最新状态、备份、载入验证、提交。试玩中的开关状态和位置不会代替原世界进度。不兼容候选显示实际载入错误并禁用预览内应用；过期候选关闭预览。快速关闭重开、载入期间重置以及失败副本均有资源清理。

## 实现边界

- `app/scene-diff.mjs` 提供浏览器和服务共用的差异定义；旧场景升级和构建哈希保持原有规则。
- `/api/candidate/review` 验证当前候选与基准，重新校验两份真实构建，返回只读数据；不信任旧的差异缓存。
- `app/review.js` 管理预览会话与异步载入代次；宿主始终只保存 `activeFrame`。
- 预览继续使用不含同源权限的游戏 iframe 和隔离 Worker；定位消息只允许预览窗口执行。
- 极大或被包围的对象可能没有合适的自动观察位置，此时显示原因，仍可在副本中走动查看。
