# FB03 修复与普通玩家流程复盘

FB03 七项产品修复和两条指定玩家流程的工程验收已完成，交付版本为 `0.14.4-preview.18 / 125f1814`。新版真人物理输入复测尚未取得，工作树清理另有下述残余目录阻断。原始七条反馈、五张截图和用户原话完整保存在 [FB03 图文记录](USER_FEEDBACK_BATCH_003_2026-09-12.md)，没有将其改写为玩家已确认通过。

这次的成功标准按用户最后的澄清收敛为两条：普通玩家进入沉浸式世界后，通过对话创造可使用的内容；或者从对话开始创造新世界，完成后直接进入游玩。成功流程不要求玩家理解源码、候选版本、检查与采用。已明确选择的权限模式和模型配置应保留；未配置过的造物会话默认自动完成。

之前的工程验证不充分。FB02 的离屏渲染会持续提供动画帧，掩盖了正常世界覆盖主界面后主界面停帧的情况；单看包中包含修复代码，不能证明玩家能走完整个入口。本轮保留失败证据，分别核对实际窗口层、真实 Rust 状态、可见 React 控件和生成后的玩法。

用户确认“现在已全屏、Esc 有效”的原话保留为本批事实，没有重新把全屏列为未确认的新缺陷。全自动也补齐了默认入口：仅当会话继承权限且全局未配置权限时，为该造物会话使用 Auto；显式 Ask／Accept edits 不被覆盖，普通工作台不受影响。真实自动采用完成后，无新输入的沉浸式对话会回到试玩；有新文字或附件时保留输入，不突然把键盘交还世界。

原 FB03-007 请求的配置是 DeepSeek Flash expires0910／max，继承权限且全局未设置，旧行为实际落到 Ask；它在迁移失败时尚未发起模型请求。对话创建入口截图及配置则是 DeepSeek V4 Pro／medium。两条验证按各自实际规则记录，不用相邻截图回填，也不换模型推断玩家能力。
