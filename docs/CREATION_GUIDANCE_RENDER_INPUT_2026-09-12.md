# 创作指导：外形能力与输入交接

将 `creation-sandbox.authoring` 从 1.6.0 更新到 1.6.1，重新生成指导目录及文本哈希，保留原有接口哈希与源码权限边界。

普通玩家生成的飞机把托管拾取器的保守覆盖范围解释成了只能使用 BoxMesh 的美术约束，又在登机与下机直接设置鼠标模式。新增指导说明：渲染、目标选择、玩法是不同的验证事项；选择回退不等于网格无法显示，也不能为了适配检查擅自降低外形要求。复杂网格的精准拾取仍须根据真实能力核实。

同时明确 DisplayServer 名称不是输入所有权凭据。载具必须保留既有控制器的输入启用、捕获状态、暂停与失焦释放；不能直接设置鼠标模式绕过状态，也不能发明不存在的接口或让测试环境跳过真实玩法。

本次只改指导与发布目录，不改生成作品、拾取器、输入 API 或测试动作。不运行产品或模型。通过现有指导接口、文本哈希和打包路由测试验证内容可按固定版本正常读取。
