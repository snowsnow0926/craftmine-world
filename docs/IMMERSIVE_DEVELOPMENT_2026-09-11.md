# 沉浸式造物世界开发记录（2026-09-11）

## 已完成

本批次为已有世界加入了紧凑创作面板和完整创作面板。两种面板共享同一个世界、会话、草稿和任务；F2 打开紧凑面板，Shift+F2 打开完整面板，Escape 按当前输入层级退出。打开创作面板会暂停游戏，返回世界后恢复，输入不会穿透到游戏窗口。

本批次加入了本地按住说话。录音最多 30 秒、单声道 16 kHz，转写结果进入同一个草稿供修改，不会自动发送。取消录音、切换世界或切换会话都会丢弃过期结果。语音识别仍需要玩家在真实 Windows 环境验收。

创作指导已经绑定到准确的底座版本和接口哈希。未知指导 ID、接口变化和不兼容版本都会明确失败，指导资源随生产插件打包。

## 空白造物世界与持久操作

已新增 `creation_operation` 世界工具，并接入真实的 Godot `index/read/patch` 源事务。它支持放置、修改、有限复制、调整时间和创建顺序机关。每次操作都校验世界、构建、运行实例、源码修订、清单哈希和目标快照；边界、碰撞、玩家重叠、重复身份和过期目标都会拒绝。

新底座没有 `world/creation.json` 时，第一次放置会建立空白创作场景。后续结果保存到 `world/creation.json`，操作收据保存到 `world/creation-operations.json`，相同操作可以安全重放，改变请求内容会被拒绝。生产插件构建清单已经包含相关编译器模块。

同时新增了纯逻辑运行时投影：它可以从 `creation.json` 生成确定性的实体、目标快照和顺序机关进度，用于验证保存后重开的一致性。当前还在把实体投影接入各个底座的正式渲染和交互层。

# 既有世界沉浸式开发记录，2026-09-11

## 已交付范围

本批开发围绕既有世界增加了可游玩模式下紧凑和完整两种造物界面。聊天、输入框、草稿、任务和世界保持在同一会话中。F2 打开紧凑造物面板，Shift+F2 打开完整造物面板，Escape 遵循当前激活的输入层，界面上的可见按钮提供相同操作。原生游戏画面不会覆盖造物面板或其选择器。

打开造物界面会通过独立的覆盖层原因暂停游戏。手动暂停、保存/检查点冻结、候选失败以及后续手动修改各自保持独立的所有权。旧版游戏使用限定范围的独立保持；插件工作台控件仍可交互。本批没有新增 Pointer Lock 请求。

本地按住说话最多捕获 30 秒、单声道 16 kHz PCM，并使用已安装的 Windows 语音引擎转写。转写文本会追加到同一草稿中供修正，不会自动发送。取消操作以及世界/会话变化会丢弃过期录音和结果。权限只使用一次，并限制在主文档；不会上传录音，也不会保留音频文件。

真实的 `godot_guidance` 工具现在会发现有界、锁定版本的第一人称装备配方及其匹配引用。未知 ID、源接口变化和不兼容版本都会安全失败。生产插件构建器包含实际指导资源，并已通过回归测试。

- 共通过 149 项针对性测试：原生宿主生命周期/几何/快捷键、旧版消息处理、语音捕获/处理/权限状态、编辑器草稿保留、指导/代理契约以及实际插件打包。
