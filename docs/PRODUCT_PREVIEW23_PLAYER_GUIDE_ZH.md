# Craftmine 世界创作测试指南

本轮仍使用原来的 PI Desktop 界面。世界列表、创作对话、素材库、版本和设置都沿用已有入口。具体交付目录、程序版本及验证结果以同目录的交付记录为准。

## 先打开一个世界

解压完整交付 ZIP，在解压目录运行 `START-PLAYER-PREVIEW.cmd`。第一次运行请保留程序目录中的资源文件。入口页可以继续已有世界，也可以从示例、个人模板或空白世界开始。

示例创建的是自己的副本。游玩已有世界、直接复用兼容素材和导入朋友的模板不需要 AI 账号；让 AI 创作或修改世界时才需要配置创作后端。

## 五项功能在哪里

| 想做的事 | 操作入口 | 完成后检查什么 |
| --- | --- | --- |
| 把伙伴、场景和玩法组合起来 | 打开世界 → 素材库 → 玩法组合 | 配置生成计划，交给现有创作对话；待真实制作与检查后进入世界试玩。 |
| 多轮修改时保留原来的要求 | 创作侧栏 → 作品目标与进展 | 写入目标和保留要求；新版本的认可状态与旧版本分开。 |
| 调整对象摆放 | 现有对象编辑器 | 预览位置和角度，再确认修改；需要时撤销。 |
| 接入自己的 Codex | 设置 → 世界创作后端 | 发现兼容安装、选择路径、登录并验证，保存设置。 |
| 和朋友交换作品与问题反馈 | 世界模板导出；素材库 → 朋友试玩与反馈 | 朋友导入模板创建独立世界，试玩后预览并导出反馈文件。 |

## 用已有素材组合玩法

“玩法组合”提供伙伴探索、雨中漫游和收集物品解锁飞行。可以保留当前场景，选择伙伴、天气及收集数量，并补充自己的要求。

先查看组合计划，再将其加入现有创作输入框。计划会列出具体素材版本、需要适配的地方和还没有实现的逻辑。例如飞机素材本身不等于已经有了收集任务，Agent 仍要制作解锁规则和适用场地。输入框中的草稿可以继续编辑，发送后才开始 AI 创作。

已有完整世界会作为当前作品继续修改。完成后请实际检查能否到达目标、完成任务和操作飞机，以及保存重开后进度是否保留。确认满意后，可以在素材库的世界发布界面保存成个人模板，供下一次创建使用。

## 保存作品目标，继续修改

在“作品目标与进展”中分别写下想完成的功能和后续必须保留的内容，例如“收集后才能登机”“继续保留城市建筑和已收集进度”。目标保存在当前世界中，后续对话会获取这些要求。

“继续这个目标”把相关要求加入当前作品的创作输入框。AI 整理的目标先显示为建议，采用后才成为玩家目标。可以查看最近的原始需求。

原生检查、AI 的完成说明和你自己的试玩认可分别记录。“我已试玩并认可”只适用于当时版本；世界修改后，旧版认可会显示为需要复查。个人创作目标不会自动装进分享给朋友的模板。

## 预览、移动、旋转和撤销

对象编辑器提供位置、角度、尺寸和颜色。对支持的普通树、石头、箱子、门和标记，可以先看引擎渲染的临时预览；取消预览不会保存对象。确认修改后沿用现有检查和采用流程，可使用撤销恢复。

这一版的临时预览适用于受支持的普通对象和标准世界源码。自定义脚本对象、任意导入模型或不兼容旧世界可能没有该能力；界面会明确显示不可用。已有组件的安装与游玩仍使用它自己的兼容条件。

## 让新玩家连接自己的 Codex

在世界创作后端设置中选择 Codex CLI。应用会查找已安装的兼容版本；存在多个候选时，选择实际可用的安装。按界面完成登录和验证后保存。

未找到 CLI 时，使用设置中的官方安装指导，安装后重新发现；也可以手动选择已经安装的程序。版本不兼容时按具体提示处理，不要把一个不可用的路径当作已连接。

本轮验证使用 `gpt-6-astra / xhigh`。兼容版本和实际账号能力以设置中的验证结果为准。本交付不包含开发者的账号凭据，也不承诺存在可公开下载的每一个精确预发行 CLI 版本。没有兼容安装的外部新电脑仍需实际完成安装与验证。

## 分享世界并收集反馈

先保存世界，在素材库发布为个人世界模板。当前个人模板使用已保存进度作为起点，需要明确勾选同意，再从个人模板入口导出 ZIP。导入副本会带入发布时的位置、探索和互动状态，不会自动把已经完成的任务归零。将相同版本的应用和模板一起交给朋友；朋友导入后创建自己的独立世界。希望从头体验时，应选择尚未完成任务的模板或从示例开始创建。

试玩者在“朋友试玩与反馈”中填写问题、复现步骤和预期结果，可选择附图。先检查反馈预览中的文字、图片和世界版本，再确认导出本地反馈文件。请对照实际预览图片，确保它能说明问题。

作者选择朋友的反馈文件，查看内容后确认保存到当前世界。记录保留原话、反馈编号和测试版本；不同构建的记录需要先核对。使用“交给 AI 检查（先编辑）”可以把反馈加入当前创作输入框，编辑后再发送。

修复完成后重新试玩，发布并导出新的世界模板。也可以在原反馈上编写回复，导出后交回朋友。文件交换由双方自行完成；应用不会自动上传反馈或替你联系朋友。

反馈文件仅包括预览中显示的文字、版本标识和所选图片，不附带账号、完整对话、系统日志、世界源码或存档。世界模板则包含朋友运行该作品需要的内容，请分别选择要分享的文件。

## 建议这次这样试

1. 打开一个已认可的示例，走动、交互，保存后关闭并重开。
2. 新建空白世界，安装博美；放置一个普通对象，预览、移动旋转并撤销。
3. 在已有世界中生成一个玩法组合，保存两条必须保留的作品目标，连续要求 AI 修改两次，再检查原玩法和进度。
4. 将满意的世界保存成模板，在另一个独立档案中导入并游玩。
5. 导出一份附图反馈，在作者档案导入、准备修复草稿，再导出回复。

反馈时尽量写明应用版本、所用世界、从哪里点到了哪里、预期和实际结果。自动检查不能代替你对流畅性、美术、可爱程度和玩法趣味的判断。
