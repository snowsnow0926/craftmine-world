# 本轮城市创作与素材复用：时间和 token

本次实际应用内创作使用 `gpt-6-astra / xhigh`。以下来自同一城市的真实终态记录；不包含开发本项目的 Codex 总控与子 agent 消耗，也不代表此前四个宣传世界的历史总量。

| 场景 | 本机时间 | 已报告 token | 说明 |
| --- | --- | --- | --- |
| 最初三轮城市组合、玩法适配与连续修改 | 三轮主机时间合计 28 分 42.698 秒 | 13,731,507 | 包括缓存输入；不含回合间的实际游玩检查时间。 |
| 最后原会话继续：当前草稿完整构建、检查，随后正常采用 | 模型回合主机时间 118.797 秒 | 4,525,479 | 未缓存输入 84,560、缓存读取 4,439,424、输出 1,495；推理 624 已包含，不再累加。自动采用发生在回合结束后。 |
| 最终完整城市模板在新档案复现、保存和冷开 | 63.420 秒 | 0 | 从最终发行 ZIP 的实际解压副本运行，无需重新调用 Agent 制作。 |
| 新世界直接复用博美、编辑树木、撤销、分享，再由独立档案导入冷开 | 346.706 秒 | 0 | 包含五次应用启动与退出核对，非单步导入时间。 |

这些是本机单次样本。重新打开已有世界或导入完全相同的模板可以零模型完成；让 Agent 根据参考世界做新规则、布局或美术仍需真实创作，不能把 63 秒承诺为任意新世界生成时间。

本城市会话连同调试共有 21 个终态回合，其中 17 个有可信创作终态计数、4 个失败回合计数未知。已报告创作小计 **57,758,019 tokens**；另有一次长历史恢复的 12 个原生维护阶段，独立报告 **2,221,586 tokens**。两项不重叠的已知小计为 **59,979,605 tokens**，包含大量故障诊断、恢复、重试和缓存读取，不能作为普通玩家每个世界的成本估计。

该长历史恢复轮耗时约 70 分 55 秒，其中维护约 67 分 12 秒，含原生网络重试与回退。后续验证中止确认、原线程恢复和 Worker 校验修复已通过，最终续作没有再次重建长历史。旧失败与长耗时记录保留。

完整总量仍为未知：未报告的失败请求不能记作零，费用和物理模型请求总次数也未提供。`522500` 是一次上下文容量哨兵，不是用量；终态总量已经包含缓存，推理明细也已经包含在输出内。传输快照数量、工具次数、回合数都不能替代网络模型请求数。
