# 轻雨城市、博美与歼二十：试玩操作

在入口页的“我的模板”中导入交付目录内的 `examples/city-flight-and-companion.zip`，再创建自己的世界。这份模板从作者保存的进度继续：六个城区保留，三个通航物品已经收齐，飞机已解锁，并保留一次起降记录。小麦处于等待状态，已有两次抚摸记录；这份模板不是未开始的收集任务。

## 城市与伙伴

WASD 行走，空格跳跃，E 交谈或收集，M 查看地图。只走过部分城区也可以继续探索其余区域。

靠近白色博美“小麦”，瞄准它按 E 抚摸；在身边按 H 切换跟随和等待。飞行前可以让它在城外道路等待。沿城外南侧道路向东可到机场，飞机在跑道近端。

## 登机和驾驶

靠近已经停稳的飞机按 E 登机。当前保存位置的机头朝南，与初始起飞方向不同；先低速转向跑道延伸较长的北端，再沿中心线加速。短按 W 增加少量油门，Q/E 或 A/D 可在滑行时转向，S 收油、空格刹车。

| 操作 | 按键 |
| --- | --- |
| 增加／减少油门 | W / S |
| 抬头／低头 | 向下／向上箭头 |
| 左右滚转 | A / D |
| 方向舵 | Q / E |
| 刹车 | 空格 |
| 加力 | Shift，油门需足够高 |
| 起落架 | G，地面不能收起 |
| 座舱／跟随视角 | C |
| 停稳后离机 | Enter |

松开 W 不会自动把油门归零，需要按 S 主动收油。达到机上提示的起飞速度后短按向下箭头抬头，松开后观察姿态，避免长按俯仰。降落时对准跑道、放下起落架，轻柔接地；落地后 S 收油并用空格刹停，再 Enter 离机。

这些是当前游戏的简化飞行操作。已完成的自动验收包括短直线起降、低速转向、返停机点及保存重开；长时间连续手感和更复杂航线仍适合由玩家在成品中试玩。

## 保存与反馈

使用应用里的普通保存，看到保存完成后再关闭。重新打开同一世界可继续此前的位置、收集、伙伴互动和飞行记录。

遇到问题时，在“朋友试玩与反馈”记录具体位置、按键、预期和实际结果，并选择能说明问题的画面。导出前核对预览与版本；作者可以把该记录交回现有创作对话继续修复。
