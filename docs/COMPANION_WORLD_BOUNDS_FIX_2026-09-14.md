# 宠物跨越原型地图边界后无法保存

真实城市测试中，雪球到 z<-80 后被旧组件的固定 ±80 范围拒绝保存。
城市实际允许 z 到 -300。原有效存档仍保留，本修复不改玩家位置或存档。

新增认可版博美 v3 和通用宠物 v3，保留旧 ZIP、模型及哈希。新版通过
`saved_position_min` / `saved_position_max` 明确配置当前世界范围；默认仍是
兼容用的 ±80，不宣称覆盖全城或自动适配任意世界。配方 3 为源码与入口完全
匹配的原版城市/沙盒提供具体配置，其他世界要求查源码。旧配方仍可复现。

保存格式、身份、名字、外观、跟随状态和互动次数保持。仅竖直方向允许与原
碰撞内缩一致的 2 毫米接触误差；不夹取、不改写坐标。NaN、Infinity、非法朝向
和计数仍拒绝，大地图合法位置也不会跳过其余字段。碰撞继续使用宠物自身形状。

只读升级计划器仅匹配完整已知旧脚本哈希，通过正常源码修改、检查和采用升级。
Agent 已自定义的代码会拒绝自动覆盖，需保留改动单独复查。

Godot 纯 CPU 的独立写入/恢复进程共通过 150 项断言，包括 z=-200、脚底
y=-0.0001868 原值、旧状态兼容、地面接触及真实宠物重叠拒绝。
这是组件验证，不代替完整城市游玩，也不增加寻路能力；真实长距离跟随、绕障
及保存重开由总控继续验证。
