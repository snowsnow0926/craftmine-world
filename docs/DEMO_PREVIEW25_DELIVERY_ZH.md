# Demo preview25 交付与启动

交付形式：Windows x64 免安装 ZIP。此次优先供用户实测和录制宣传片；提交目标为北京时间 **2026 年 9 月 15 日 24:00 前**。

## 启动

1. 正常退出旧版应用，将 ZIP 完整解压到新目录，不要直接在压缩包里运行。
2. 双击根目录 `START-PLAYER-PREVIEW.cmd`，使用 preview25 的独立资料目录。
3. 需要继续原 preview23 世界、对话和模型配置时，改用 `docs/CONTINUE-PREVIEW23.cmd`。两种启动方式选择一种即可。

现有示例可以直接游玩。新的 AI 创作需要在应用里配置自己的服务；DeepSeek 的 1M 上下文、384K 最大输出和最高思考设置见 `docs/DEEPSEEK-MODEL.zh-CN.md`。交付包不附带测试使用的 API Key 或私人测试资料目录。
