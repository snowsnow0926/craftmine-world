# NB1：宿主冻结的造物愿望检查

日期：2026-09-11。适用计划：`CREATION_NEXT_BATCH_PLAN_2026-09-11.md` NB1。

## 已实现

玩家请求进入宿主时，从真实运行时捕获实体集合及命中对象，冻结有界要求。模型只读这些要求；`godot_build_start mode=check` 由插件取宿主绑定加入核心作业。SQLite 中保存要求及摘要，继续作业、重启和检查描述符保留相同要求。自动采用再次比较宿主冻结要求与核心作业，未知愿望返回 `CREATION_REQUIREMENTS_NEED_REVIEW`，不会把“能启动”当成“愿望完成”。

支持明确的单句：在这里放一棵树/一块石头/一个箱子/一扇门/一个标记；把这棵树/这个对象/它放大到 2–9 倍；删除这个对象/这棵树/它。顺序门采用明确格式 `依次触碰marker-a、marker-b后打开door-a`，要求对象已存在且是标记与门。未覆盖表达、复合句及任意新脚本需求保持待验证，不丢掉句子后半段。

直接编辑支持宿主明确的尺寸、颜色、删除要求。撤销要求只能由宿主在写入前读取正式版本的 journal inverse，核对当前对象与 inverse.after 后冻结 inverse.before 或对象不存在；模型工作稿或渲染端 journal 不能作为来源。NB2/总控负责直接编辑入口接入。

## 实际检查与证据

- 在真实 Godot 候选加载后、运行后分别读取观察信封，核对世界/构建/实例身份及实体 ID、种类、位置、实际 Node3D 尺寸、实际主材质颜色、五类数量；简单编辑同时保留未涉及的已有对象。
- 顺序门在独立候选引擎中恢复该候选的真实初始存档，先确认门关闭、先触碰第二个标记仍关闭，再重置并依次交互，最后一步才打开。只使用私有运行时存档/恢复、等待和真实射线命中后的 interact；不发真实鼠标键盘、不请求 Pointer Lock、不保存正式世界。
- Rust 验证两阶段实体证据及门交互轨迹完整性，缺失、错误尺寸、错误对象、门提前打开均不接受；保留原第一人称靶子反馈检查契约。
- 数字摘要采用 IEEE-754 位编码后按键排序，避免 JavaScript/Rust 对 0.000001 的文本序列化差异。双方共享黄金摘要测试。

## 验证

39 项宿主/工具连接测试通过；11 项 Rust requirements 相关测试通过（含原反馈回归与 SQLite 重启证据）。桌面 TypeScript 检查通过。`tests/creation-requirements-web.mjs` 使用真正导出 Web PCK、独立 headless 浏览器，14 项检查覆盖正确尺度、错误对象/尺度/颜色/数量和能正常运行的无条件开门反例。记录见 `docs/evidence/next-batch-nb1/`；最终统一生产执行链由总控集成验收。

这些是有界运行证据，不能宣称证明任意程序未来行为，也不替代真实模型首次成功率、玩家体感或物理麦克风测试。

## 第二轮：冻结评测语句与普通实体脚本

已加入精确语句：`把这棵树变大一倍`（同一对象变为原尺度两倍）、`复制这棵树两个，排开一点`、`把时间设为18点`、保留已有内容的再次放置/副本放置、明确十六进制颜色修改。复制必须是两个新稳定 ID，尺度和颜色一致，实际碰撞盒与其他实体分离；时间要求同时检查实际采样。评测输入在解析改进前已冻结，这一轮结果属于已知输入改进后的验证，不能再称为未参与调优的留出评测。

支持一条完整有限新行为愿望：`让这棵树可以按E砍伐，砍掉时给背包增加一块木头，5秒后重新长出来。保存重开后保留木头和树的生长状态。`。宿主冻结树 ID、wood 增量 1 与 300 物理帧；底座只提供一般化 entity-behavior 接口，采伐、计时、奖励和脚本状态由普通脚本实现。测试作者的实现位于 tests/fixtures，既不进入底座也不进入模型指导。

实际候选中执行首次砍伐、隐藏且关闭碰撞、重复交互不重复奖励、中途快照、先恢复默认再恢复中途快照、检查完整进度相等、等待生长和再次采伐。观察的物理帧计数不进入存档。初版检测器仅累加 wait 参数，漏算协议往返期间的后台物理帧；真实测试发现后改为读取运行时真实 physicsTick 动态等待，在第 270–299 帧窗口仍未长成，在第 300–360 帧窗口已长成。该容差窗口是运行证据的边界，不宣称逐帧证明任意未来行为。

第二轮结果：41 项宿主/工具连接测试通过，13 项 Rust requirements 测试通过，30 项真实 Web 属性/复制/时间/门验证通过，8 项真实 Web 普通采伐脚本检查通过（正确实现与奖励翻倍、提前生长、恢复丢失三个可运行反例）。既有生产执行器协议测试 41 项通过、1 项按原测试条件跳过；桌面类型检查通过。采伐正例同时验证实际消失/无碰撞、背包增量、存档恢复与重生；没有将作者夹具计入真实模型成功率。
