# 可玩宠物行为开发与验证记录

本次新增组件脚本及隔离引擎夹具，根工作区负责通用存档与互动派发，其他 Codex 子 agent 提供真实原创犬模型及包装。没有修改现有玩家世界或冻结成品，没有模型调用。

完成平地跟随、近距停止、墙体阻挡、近距抚摸反馈、两实例独立名字/外观/跟随/位置/次数。状态严格采用 `settings` / `sourceSettings` 合同；普通犬与白博美分别用半径/高度 0.75/0.77、0.36/0.48 米的独立圆柱，脚底不因外观改变而上移。完整接口与边界见 `desktop/godot/components/pet-companion/README.md`。

## 保留的失败与修复依据

1. Godot JSON 十进制输出与内存 Vector3 相比产生约 2e-18 差异。改用实际 JSON 正规化 snapshot，严格字段及数值比较不放宽；真实 JSON 往返和非轴向 yaw 均通过。
2. 恢复后的动态 broadphase 仍保留上一帧位置。`pet-companion-JDyJpc` 记录原生查询漏掉已移动玩家/同伴；`cN6X1i` 表明显式 `body_set_state` 仍未刷新；`wWF6j5` / `wTa0zG` 的独立 scratch space 也需帧更新。失败日志保留在本 worktree 的 test-results 中。生产实现不等待隐藏/暂停页面的物理帧，而对已知实际 Cylinder/Capsule 作同步精确交叠计算，剩余静态世界仍原生查询。水平、端帽、接触、分离差分及旧位置假阳性回归通过；未知动态几何明确拒绝。
3. 换大外观后贴墙、玩家重叠、同伴重叠及超过 2 毫米的入地均拒绝。所有角色恢复完毕后由宿主统一执行，失败回滚；不能用旧玩家位置提前判定。

本记录证明组件级真实引擎行为和网格包络，未声称产品完整 E 路径、保存事务、成品画面或模型自主创造已验收。首版仍是保守圆形占地、平地跟随，不扩展寻路。

后续根审核发现无效配置曾在注册持久组件组之前返回，导致宿主可能漏掉坏组件。现将注册放在 `_ready` 最前，仍由 `configuration_error` 阻止状态验证；ID 使用与 registry 一致的 1–128 位字母数字/点/下划线/连字符，完整匹配，不允许冒号和尾随换行。新增空 ID、冒号、换行、未知外观、非法速度五类检查，均可被组枚举发现且不能验证自身 snapshot；只补合同回归，未扩展视觉或物理范围。
