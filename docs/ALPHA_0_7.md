# Alpha 0.7：连续创造，先看变化再应用

2026-09-08，M3 验收完成。个人创作 Alpha 的整体目标仍在进行，下一阶段为素材导入与绑定（M4），然后完成采集、制作、战斗与任务的完整世界（M5）。

## 使用变化

- 候选就绪后点击“查看变化与预览”。可以比较当前与候选定义、参数和源码，并在独立副本里实际试玩。关闭或丢弃不会保存副本进度；应用时仍保留原世界最新进度。完整存档候选会明确提示恢复文件中的进度。
- 点击对话框下方“创作方向与长期约定”，写下世界方向或特定对象的约定。保存后用于下一次生成，对话变长或服务重启后继续保留。
- 已应用需求保存原文和对应版本；重要要求可以整理为长期约定。已应用模块仍按原有记忆库保存完整源码和版本。
- 模型提交的候选检查失败时，最多自动修复两次，所有尝试共用 240 秒总时限，可随时取消。开发工作区保留失败源码、实际诊断、每次检查和读取过的项目上下文。
- 已保存的游戏源码错误会显示在开发工作区。“描述这个问题给助手”准备带现场范围的修复请求，发送后使用实际错误和原进度。

方向最多 4000 字，长期约定最多 24 条，每条 1000 字；自动保留最近 64 条已应用需求，每轮最多检索 8 条。方向和约定不随对话裁剪。当前完整存档和模块导出不包含整个项目的方向、对话或所有需求历史。
