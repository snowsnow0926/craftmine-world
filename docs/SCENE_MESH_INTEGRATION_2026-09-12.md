# 普通无碰撞物件选择集成

将有限 BoxMesh 拾取接入固定 creation-sandbox adapter，并纳入 Rust 源码
保护、实际导出 PCK 字节核验及新世界 materialize 清单。实际相机中心射线
同时用于物理和三角形查询；相同深度保留物理交互优先，不声称两种节点
因此就是同一个对象。场景切换当前相机后，不再从旧 Player 相机取指向。

未知遮挡或超限明确停止本次射线选择，避免把“这个”解释为后方地面。
已有最近结果显式选择保持原逻辑。HUD 辅助球与线框只在实际根节点、
无子节点、内建几何／材质形状符合已有辅助物件时排除。

真实隔离 Godot adapter 探针 13 项通过，涵盖无碰撞 BoxMesh、相机切换、
未知近处几何阻挡、两种近乎重叠的真实碰撞体区分以及原引用生命周期。
这不是实际宠物的整条产品验收。当前仍在整合固定旧源码迁移与新冻结
构建，不能将 prototype 支持范围宣传为任意 3D 模型选择能力。

打包预检曾因分发清单仍是旧 adapter 字节而拒绝。已逐项核对本轮自行编写
的两个固定 helper，加入确切路径的源码分发清单生成范围，再从干净提交
刷新字节与哈希。没有扩大第三方文件许可、跳过未知新增文件审核或放宽
包校验。分发清单刷新及后续完整构建的日志单独保留。
