# 静态组件优先检索指导（2026-09-12）

将 `creation-sandbox.authoring` 从 1.6.2 升至 1.6.3，并用现有生成器更新 catalog 与正文 SHA。没有修改底座接口引用、托管源码权限、构建文件或原六组作品。

指导前部新增实际源组件链：常见静态外观先按用途小范围 `godot_source_library search`，用真实目录 AssetRef 调用 `read`，核对 rootRef、入口、毫米尺寸、碰撞、导入设置、兼容性和许可，再用同一精确目录引用 `propose`。归档哈希与内部包根哈希分别说明，不能互换。位置只能来自明确已知坐标；省略位置是模板默认，不能声称自动完成“这里”的指代。

方案保留正常玩家安装提案、源码检查和候选采用，不让模型搬运 ZIP/base64 或误走旧 package_library。要求本轮复用已读引用和摘要，不重复全库读取；没有合适素材时仍按玩家原要求原创，不用少量库存宣称全部城市、动物和飞机已有组件。静态外形也不代表已经具备开门、驾驶或战斗玩法。

已逐项核对 `manifest.json` 中工具 schema、`source-library-service.cjs` 的 search/read/propose 实现，以及真实资产目录分页字段和构建包装器的 entry 元数据。使用现有指导和源库测试验证：哈希/接口适用性、分页正文/示例读取、打包后真实工具路由、精确资源引用、提案冻结/过期及位置限制，共 15 项通过。打包测试第一次因新工作树缺少 esbuild 无法启动，复用隔离依赖后通过；未弱化测试。

本次没有调用模型。指导是否减少重复造型或提升采用率仍需之后真实玩家任务观察，不能凭文案和归档检查宣称效果已达成。
