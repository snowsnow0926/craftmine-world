**建议先按这六件事试玩。**

1. 新建一个 3D 第一人称世界，观察世界居中、对话在右的布局；调整窗口和聊天宽度，看看是否顺手。
2. 进入游戏，按画面中的操作说明移动、查看装备和射击反馈。关闭客户端，再从同一个入口打开，检查进度是否还在。
3. 新建一个俯视世界，尝试人物、商店或任务交互；在两个世界之间切换，检查是否各自保留进度。
4. 分别试一个横版和采矿世界，观察移动、碰撞、跳跃、战斗，以及底座提供的挖掘或放置操作。它们目前仍是简单原型内容。
5. 选择已有参数调整入口，修改一个支持的值，先预览并取消，再重新修改并采用；留意正式世界和游玩进度是否符合预期。
6. 用一个专门的试玩世界试复制、备份和恢复。遇到问题时，记录操作步骤和截图；可以使用客户端的问题记录功能补充文字。

如果要重点测 AI，建议一次提出一个具体需求，例如“修改当前武器的准星样式”或“调整这个商店的一个商品”，再提出第二次修改。重点观察：AI 是否找到实际工程、是否提供可运行的结果、预览是否符合要求、应用后进度是否保留。本轮真实模型创作尚未验收，你的结果属于新的测试证据。
