# 素材成组安装与真实视觉反馈（2026-09-12）

## 本批目标

上一批 18 个预制资源和林间入口已进入成品；普通模型经过自然纠正成功复用橡树，但多件提案逐个安装会过期，模型没有正式游戏画面的工具。此轮补两条通用能力，不扩大素材数量来掩盖使用成本。

## 成组提案

`godot_source_library` 增加 `propose-group`，输入 2..8 项精确资源目录引用及各项可选位置。同一引用可重复，每次是独立实例。主机读取真实归档，绑定一次世界和源码身份，持久保存有序清单；模型不搬运 ZIP，不提供源码身份或主机路径作为权限。

确认继续使用原作品面板的 `installSourceProposal`，页面列出成员及各自位置，一次确认整组。底层设计为一次源读取、各资源与跨资源预检、一次原子文件事务和一次检查；重复相同操作重用回执，位置或清单变化不能冒充同一请求。多个原归档哈希逐项保留，不用一个虚构聚合哈希冒充单包。

当前提案、原生服务回执投影和界面接口测试共 21 项通过，包括单包旧路径；真实核心成组事务与最终成品仍在集成验收。有限包容量是资源协议约束，不是额外模型 token/调用额度。

## 视觉反馈

新工具计划只抓绑定游戏视图自身，不读取桌面、不调整或显示窗口、不恢复暂停、不操作键鼠或 Pointer Lock。正式世界和候选预览显式区分，捕获前后校验相同世界、构建、实例和视图。真实 PNG 应沿既有工具 `text + images` 通路进入模型，不能把 base64 JSON 当作视觉输入。

当前实际模型配置声明支持图片，但所用服务端别名能力尚未验证。需分别证明捕获成功、适配后请求携图、服务端接受或拒绝；不自动换模型或额外调用第二个模型。声明不支持图片时明确不可用，不能静默丢图后声称已经看图。

本文件记录建设范围与阶段状态，尚不声称这两项已经通过最终成品或真实模型验收。
