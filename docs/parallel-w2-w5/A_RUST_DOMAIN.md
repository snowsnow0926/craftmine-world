先读同目录 `01_COMMON_RULES.md`、`02_HANDOFF_CONTRACTS.md`、`03_REPORT_TEMPLATE.md`，以及项目根 `AGENTS.md`、主计划和第 5 批报告。代码根目录 `D:/Craftmine World`，从 `dispatch/w2-w5-v1` 创建你自己的 `codex/dispatch-a-<唯一后缀>` 分支和独立工作树。只提交该分支，回传后由协调者验收合并；不改主目录、不启动自动循环或子 Agent。

测试必须独立 headless/纯逻辑、独立数据，禁止真实输入、Pointer Lock、窗口显示/置前和用户浏览器操作。不运行两个历史输入测试。不得改个人 `.craftmine` 或旧 PI 程序。

## 必须完成

1. **不可变作品库。** 在 Rust 管理的领域存储中增加持久索引。作品代码、参数、素材/扩展依赖与包哈希可精确读取。支持中文名称/关键词、标签、类型、作用域与版本过滤；分页不返回整个仓库。先用可验证的本地检索，不引入向量服务。
2. **可信入库。** 从真实已应用构建、资源选择和应用/验收记录形成可复用对象或创作组。区分草稿提议、验证通过、实际应用；模型自称成功或随便填写 evidence 引用不能使作品 validated。重复 operationId 不产生重复版本，同版本不同内容拒绝。
3. **固定版本安装。** 沿用现有作品包格式，在目标草稿中正确重绑对象、行为、共享物品、素材与扩展引用。支持冲突报告和一致的 ID 映射，依赖缺失不半安装。提交经现有 workspace 事务；不直接发布世界。已应用同一份作品的第二个实例也应有独立对象身份。
4. **类型化记忆。** 实现项目规则、用户纠正、经过验证的经验、任务历史的来源与作用域管理；核实源码/运行器变化后标待复验；退休/替代可追溯。第二世界默认不混入第一世界的私有规则。
5. **显式任务恢复。** 崩溃后租约与未决作业有终态，不能永远 WORLD_BUSY。恢复必须核对任务、草稿、回执与最新世界；使用新代际拒绝旧写入。玩家显式恢复/丢弃，默认不重放模型请求；保留未应用代码和已经提交的应用结果。
6. **预算与上下文事实。** 按 02 提供 task.context 和预算预约/结算接口，支持 B 重建短事实、任务纠正引用和剩余额度。把请求、摘要、评审及重试放在同一任务账本；未知消费、重复结算、停止后迟到结算和跨压缩额度不归零都可复核。模型不控制可信账本值。
7. **备份恢复内容层。** 为 E/C 提供一致快照导出、校验和原子恢复。包括世界、最新进度、固定作品/素材/扩展、必要来源与证据；默认排除凭据。恢复先在临时区域校验，损坏、版本不兼容或提交失败不能破坏原世界。旧档只做副本迁移，不能直接搬走或清空用户目录。

采用增量数据库迁移和单一写入者。大包/读写作业要有大小/数量上限、取消与回执；不把现有 2 MB/资产等限制静默删除。确需扩展限制时给真实样例和资源控制证据。

- 真实 Rust 进程重启后，作品、版本、依赖与 hash 不变；同 ID 重试只写一次，内容不符拒绝。
