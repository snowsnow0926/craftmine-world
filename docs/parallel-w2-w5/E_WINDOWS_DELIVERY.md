- 凭据往返、旧格式迁移、损坏密文、系统保护失败与跨用户不可解密的情况有测试；不把加密文件旁边的明文密钥当作系统保护已完成。

- 没有隔离环境时仍完成安装包、校验脚本和复现清单，明确写“干净系统未验证”；不能在用户主机静默卸载旧版、重启电脑或修改系统保护来凑成绩。

- 当前分支不含 A–D 的最终代码时，产物仅是本组验证包；最终交付包由 G 集成后重建。
