# 给 Agent F 的派工提示词：原生真实创作与最终验收准备

你负责 craftmine world / 最中幻想 **F 组**：建立能揭示实际问题的原生验收脚本和证据体系，覆盖 W2–W5。你可以先在基线上完成测试基础设施，随后由 G 接入其他组复验。不要把“脚本已经写好”报告为“所有功能已通过”。

先读本目录 01/02/03、根 AGENTS.md、主计划、第 5 批报告，以及 `tests/desktop-native.mjs`、`tests/live-pi-drafts.mjs`、已有严格 headless 入口和第 5 批证据。仓库 `D:/Craftmine World`，从 `dispatch/w2-w5-v1` 建独立 `codex/dispatch-f-<唯一后缀>` 分支/工作树。回传后统一验收，不合并 master、不推送、不创建自动循环或子 Agent。

## 最重要的约束

必须先检查将启动的程序具有现有原生隔离保护，再启动独立 offscreen/headless 进程与标记过的测试 profile。初始化禁用 requestPointerLock/window.focus，检查隐藏、不可聚焦和零输入审计。不操作用户的浏览器，不运行 click/fill/mouse/keyboard 或两个历史输入测试；测试结束回收自己的进程。

只使用真实生产代码路径。原生 PI 的真实会话/工具分发和模型请求必须进入实际 Rust/插件/游戏链。可以用受信页面脚本或 DOM requestSubmit 完成玩家应用的程序化验收，但不能用假 host session 替代原生 Agent 循环。

## 必须交付的场景

1. **W2 自动创作闭环。** 从空世界与实际 PI 会话开始，由当前配置真实模型生成树，再要求变矮/移动；检查、评审、预览后由实际面板应用。完整关闭重启，进入新会话，检索并使用 A 的精确旧树版本。记录真实源码、工具执行与实际世界变化，不能只判断模型说“完成”。
2. **需求错误反例。** 能运行但只变色没有隐藏的实现应失败；保留正确实现通过。扩展/素材缺失、过期草稿、伪造身份、重复请求/丢回执、取消后的迟到结果应被实际入口拒绝。
3. **W3 三次强制压缩。** 一条真实任务走 PI 的真实压缩机制至少三次后仍完成并应用；保留原始目标、用户纠正、草稿、证据及累计预算。另测树已完成后加花、取消旧任务换新需求、摘要失败/模型失效、小窗口、多工具和两世界切换。只产生压缩日志或文件不算绿色收尾。
4. **恢复和数据保护。** 消息、任务、世界三层恢复分开记录；进程在补丁/验证/应用/保存不同阶段中断后，源数据/草稿可恢复，旧代际不能继续写入。重复回执不能重复扣料或发奖。
5. **W4 真实玩法。** 用 D 的组合内容与实际游戏事件验证生命、近战、射击命中/超距/冷却/弹药/死亡/奖励；重启后状态正确。验证真正调用扩展的 behavior 和扩展空实现反例。不能用 HUD、返回命令或复写测试期望替代最终状态。
6. **完整桌面回归。** C 的项目/会话切换、模型设置、流式停止、工具/文件/差异面板、主题、尺寸持久化、两种布局、选择上下文和世界保存，在实际链路中保持正确。
7. **W5 程序包与系统环境。** 在 E 的包上重复关键链路，核对资源/源码 hash、离线打开、备份/恢复、升级失败保护及诊断脱敏。没有授权干净 Windows 环境就报告未验证，并交付具体复现清单；不要悄悄使用用户主机当测试机。
8. **测量与失败报告。** 记录启动、峰值内存、帧表现、验证耗时、模型用量与包体积。先留基线，再提出明确、可复跑的个人可用版性能门槛与配置交 G；没有门槛不能只凭一个数字宣称性能达标。记录测试期间机器负载和环境，不能在多组同时构建时宣称稳定性能结论。失败与修复后复验分开保留。

## 实施和依赖

代码放 `tests/dispatch/f/`，原生辅助模块用 `craftmine-acceptance-f-*` 命名。不替 A–E 改产品逻辑：遇到问题提交最小复现、预期/实际和具体负责组。测试接入公共 index/协议时交 G 的 integration.patch；允许在自己的工作树临时接线实际运行，但记录 overlay hash，并按 01 还原公共文件后交付补丁。

A–E 未完成时：先完成真实基线场景、测试生命周期/资源限制、可运行入口、负例和契约测试；依赖场景标 `dependency_missing`。不要一开始等待全部组，也不要用假库/假预算把待集成场景刷绿。

真实模型仅使用既有授权测试配置，记录实际 model ID 和 thinking。每条链路必须设置调用/总时限/压缩上限，摘要与评审也计入；到期或无凭据明确失败/未验证，不偷偷换模型或无上限重跑。不得把密钥写进报告、命令行、截图或测试证据包。
