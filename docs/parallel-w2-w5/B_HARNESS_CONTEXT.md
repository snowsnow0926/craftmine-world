你负责 craftmine world / 最中幻想 **B 组**：补齐 W2 的原生创作上下文和 W3 的请求预算、提示词、自动压缩与任务恢复。实际开发并生成报告，主循环必须继续复用 pi。

先读同目录 01/02/03、根 AGENTS.md、主计划、第 5 批报告和相关 vendor 指令。项目 `D:/Craftmine World`，从 `dispatch/w2-w5-v1` 建立独立 `codex/dispatch-b-<唯一后缀>` 分支与工作树。回传后统一验收；不合并 master、不推送、不创建自动循环或子 Agent。禁止真实输入、Pointer Lock、显示/置前测试窗口和个人数据写入。

阅读 `vendor/pi-desktop/packages/agent-runtime/src/runtime.ts`、`session-context.ts`、`plugin-session-context.ts`、`mode-prompts.ts` 及现有压缩测试。Electron 的 sidecar/检查点与插件桥先只读；世界评审见 `plugins/craftmine-world/review-jobs.cjs`，现有世界事实见 Rust 和 02。

## 必须完成

1. **按请求重建世界上下文。** 在第一次请求、下一步、压缩恢复、模型切换和显式任务恢复时，查询 A 的可信事实。包含当前目标/纠正、任务代际、世界/草稿版本、已改资源、待决检查与回执、作品检索引用和预算；大源码与轨迹按需读取。
2. **分层提示词。** 分开稳定产品规则、当前需求、机器事实、可用工具、检索指导和历史解释；模型摘要不得改写版本或权限。中文需求、引用中的恶意指令、已完成历史任务和后续纠正要有针对性测试。沿用运行器地面/mesh 事实，不让评审按其他引擎习惯猜测。
3. **完整请求预算。** 在最终发送边界覆盖 system、messages、tool definitions、附件、输出和工具结果预留；分别记录估算与实际用量。创作、摘要、评审和重试经 A 的同一任务账本，不因压缩或模型切换重置。采用当前配置模型的窗口，超限/失效/超时有界失败并保留草稿，不静默换模型。
4. **有限上下文的评审。** 对大世界使用与需求/修改相关的真实资源、差异和有来源的分段证据。不能随意截掉关键依赖再声称评审完整。短输入与长输入的事实一致；既有 180k 保护不能被简单移除。
5. **压缩后继续正确任务。** 保留原始对话和压缩记录，宿主重新注入机器事实；完成/取消的任务不会因摘要再次执行。至少三次强制压缩的测试走真实 PI 压缩路径，不手工增加计数或伪造 compaction 文件。上下文重建失败时保留工作，不自动进入丢失背景的新窗口。
6. **停止与三层恢复。** 对话流式内容恢复继续复用 PI；任务恢复用 A 的租约/代际/回执；世界恢复用既有事务。取消传播到主模型、评审、摘要和工具返回后的后台作业；迟到成功不能覆盖停止。续作/丢弃依赖玩家明确操作。
7. **世界任务的工具权限。** 初始只激活必要世界工具，其余按需查询。通用 Read/Write/Edit/Bash 等不能绕过领域事务读密钥或修改正式存档；必须有实际执行边界，不只在提示词中提醒。保持 PI 桌面功能，按宿主可信任务作用域限制工具。记录能证明与不能证明的进程权限边界，不能宣称普通插件已经有完整 OS 沙箱。

## 验收重点

- 小窗口、中文、大工具定义、附件、模型切换均进入最终预算，使用量统计不重复叠加 reasoning/cache。
- 同一任务三次压缩后保留真实草稿、最新纠正和剩余账目；先做树后加花不会重复造树。
- 取消后新任务、旧模型晚到、服务崩溃、摘要失败、回执丢失不会重放写入。
- 两个世界来回切换，规则/作品引用/目标不串；任务正文里的伪造身份不能生效。
- 对直接调用通用文件/命令工具绕过世界事务做反例测试，记录宿主侧还需 G 接入的约束。
- 保留相关 PI 运行器回归。真实 DeepSeek 的三次压缩绿色收尾由你与 F/G 的最终原生场景共同验证；离线夹具通过不能替代它。
