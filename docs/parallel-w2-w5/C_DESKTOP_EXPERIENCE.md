# 给 Agent C 的派工提示词：完整 PI 桌面与创作体验

你负责 craftmine world / 最中幻想 **C 组**。用户明确要求前端尽量贴近 PI-Desktop 的完整桌面体验，并强化世界创作功能。请在真实现有组件中开发，不只做静态效果图或另起一个简化聊天网页。

先读本目录 01/02/03、根 AGENTS.md、主计划和第 5 批报告。从 `D:/Craftmine World` 的 `dispatch/w2-w5-v1` 建独立 `codex/dispatch-c-<唯一后缀>` 分支/工作树；回传后统一验收，不自行合并、不推送、不启动自动循环或子 Agent。测试绝不抢鼠标键盘、Pointer Lock、焦点或用户浏览器。

## 阅读与边界

阅读 `vendor/pi-desktop/apps/desktop/src/` 的现有导航、会话、输入框、设置、工作面板及主题；特别核对 `components/CraftmineNavigation.tsx` 和 `styles/craftmine.css`。世界工作面板源文件是 `plugins/craftmine-world/world.html` 和 `view.mjs`，不要编辑 build 目录中的生成副本。

世界保存、预览、评审、应用与退出已经接通。继续使用这些流程及原生桥的授权，不把未保存/不确定应用结果当成可以随便关闭的页面状态。

## 必须完成

1. **保留完整 PI 功能。** 项目/会话侧栏、流式回复与停止、工具详情、文件/代码差异、模型设置、主题、分栏和多面板状态继续可用。默认中文，避免窄栏文字截断；不以删除原功能换取界面简洁。
2. **清楚的创作工作台。** 世界、候选差异、检查/评审与聊天之间能顺畅切换；显示生成中、待检查、检查失败、可应用、已应用的真实状态。关键动作直接可见，堆栈、哈希和长轨迹按需展开。
3. **作品库和记忆界面。** 消费 A 的检索/精确版本/依赖/来源接口。支持搜索旧树/花/玩法，查看来源与是否待复验，选择固定版本安装到当前草稿。展示项目规则与用户纠正的作用域、停用/替代；不能用一段聊天摘要冒充作品库。
4. **任务恢复与预算反馈。** 用 A/B 状态解释中断原因、已保存草稿、续作/丢弃、当前目标和预算；停止明确生效。检查过程中切换世界或开始新需求，不出现旧进度写入新项目。
5. **创作/游玩两种布局。** 利用现有面板布局切换，并保存尺寸/状态；返回创作时保留聊天与任务。只有玩家主动操作才进入游戏控制，布局切换和自动验收不能主动请求 Pointer Lock。
6. **选中对象上下文。** 将实际世界选择转换为可见、可移除的需求上下文；携带 world/build/object 身份，经宿主核对。与 D/G 协调事件接口，不能由 UI 或模型虚构选中对象或静默引用过期构建。
7. **备份、恢复和诊断入口。** 消费 A/E 的能力状态及授权桥，提供可理解的操作与失败恢复提示。恢复前说明将打开什么数据；失败保留原世界。凭据状态只显示系统保护结果，不展示密钥；新手指引连接到 E 的真实操作文档。

注意：写入事实由 Rust 管理，UI 不能自己维护另一本正式世界/作品数据。审美意见仍是建议；失败需求不能绕过验收直接应用。

## 验收重点

- 实际 React/插件组件的深色、浅色、窄窗口与宽窗口布局；中文文本、工具列表与代码块可读，表单有清晰标签和焦点样式。
- 项目/会话/世界快速切换、流式停止、面板尺寸与布局重启持久化。

- 同一作品不同版本、缺依赖、过期证据、加载错误和空搜索有正确界面。
