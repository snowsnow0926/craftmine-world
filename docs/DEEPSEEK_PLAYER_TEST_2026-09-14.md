# DeepSeek 普通玩家测试与修复

用户授权读取本机附件指定的模型和 API Key，在应用中按真实玩家流程测试并修复发现的问题。
附件仅在测试控制进程内读取，凭据由独立客户端原有 Secret Store 保存；不写入源码、
报告、命令行或发行包。输出脱敏，保留失败记录。

## 原配置与已确认问题

实际玩家原配置：上下文 500,000、最大输出 384,000、最高思考，图像与文档输入已开启。
附件指定 `deepseek-v4.1-flash` 和官方 API 端点。通过普通应用请求验证，原名称得到
HTTP 400；失败记录保留。随后核对官方 2026-09-10 发布说明：V4.1 Flash 的实际 API
名称就是 `deepseek-flash`：<https://deepseek.com/news/deepseek-v4-1-flash/>。
测试驱动通过显式 `--api-model-id` 采用官方名称，同时记录附件原名、实际 API 名称和
依据；产品没有自动切模型或失败回退，附件未修改。

原错误来自过早压缩与本地任务策略叠加：输入、384K 输出预留、工具余量整体达到窗口
85% 就压缩，约 39K 完整估算输入即触发；8 次后本地拒绝继续。只读复制原失败档案后，
在 preview.24 正常 Composer 中发送继续，再次得到相同错误，保留为失败基线。

## 本轮修复

- 保持玩家配置和实际请求输出额度，85% 提前线改为作用于扣除输出和工具余量后的输入
  容量。500K/384K 配置对应输入容量 113,952、开始整理的估算输入阈值 96,859。
- 界面区分上次请求的窗口剩余比例与当前配置的输出／输入预留，不声称配置推算为实时占用。
- 新普通任务不再默认限制累计请求、压缩次数或整轮时长，继续记录用量并保留取消与单次容量限制。
- 不擅自改写旧任务限额。提供明确玩家动作，审计解除旧任务的本地次数／时长限制，保留
  token 预算、草稿、计数与失败历史，然后按原任务恢复流程继续。

## 验收流程

使用独立 offscreen 应用与独立数据目录；不用真实鼠标／键盘，不置前或操作用户窗口。
先在原奥格瑞玛大帐篷和原对话副本上测试恢复与角色制作，再验证检查、应用、实际画面、
走近／互动、多轮修改和保存冷开。按真实目标处理澄清；不把动态玩法改成静态摆设。
遇到模型 ID 或服务能力错误保留原始证据，不偷偷切模型或关闭玩家开启的能力。

原档案只读复制证据及测试数据：
`D:/cm-deepseek-player/test-results/desktop-native-product-oUgGvo/`。
这是各文件时间点复制加两份 SQLite 在线备份，不冒充暂停应用后的全档案一致快照。
原世界、会话、任务与 3/6 探索进度保留；原用户资料未被测试改写。

## 第一轮真实恢复与新增问题

原档案累计 338,391 token、8 次压缩和失败记录均保留。经实际任务页的“解除本地次数
与时长限制后继续”表单恢复同一世界、会话和任务预算归属；没有直接改写数据库。
集成过程中发现 Main 回执未接受数字时间戳、私有父进程缺少路由，分别修复并保留
失败前后测试。这些准备失败没有冒充模型创作结果。

源应用 `59af14d2` 的真实续作 turn `13f568f7-a73a-4796-8322-d7594c843fa7`：

- 9 分 4 秒，40 次 API 请求，1,100,433 累计 token（包括缓存读取 450,304；输出
  109,642，其中推理 63,887）。累计用量不是单次上下文占用。
- Blender 真实生成并导入暗黑游侠角色，修改源文件，Godot 检查通过。
- 新增 11 次压缩。摘要只保留短的最新玩家请求，并未重复携带整段旧对话；主要问题是
  世界事实和检查读取不断返回大段相同检查日志，压缩后又读回，形成循环。
- 配置及界面为 max，但新 API 名称缺少思考映射，实际 SDK 将其降到 high。已用该
  独立档案绑定、实际模型目录和同版 SDK 确认；不能把本轮称作最高思考验收。
- 恢复入口遗漏新的创作授权绑定，检查后返回 `CREATION_AUTO_APPLY_NOT_AUTHORIZED`。
  因此该轮“全自动完成”不通过，后续操作员手动应用不能改写这个结论。

通过普通候选流程先预览再应用后，角色实际出现在帐篷中。直接跳过预览会得到
`GODOT_PREVIEW_REQUIRED`，旧世界保持可用；这项预期保护的失败记录也保留。
私有测试输入走实际 Godot 事件处理器，向角色靠近后玩家位置真实改变且仍在地面。
保存后正常退出再冷重开，完整存档快照相等，角色所在构建、位置和 3/6 探索进度保留。
两个应用进程正常退出，焦点、Pointer Lock、页面错误和关闭失败审计均为空。
这验证分段输入功能与持久化，不代表连续真人操控手感或角色美术质量已通过。
