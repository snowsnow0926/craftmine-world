# 双世界玩家操作说明

Windows 客户端的日常操作是：进入世界 → 打开对话 → 描述想要的变化 → 继续游玩 → 保存退出。

## 第一次打开

完整解压发行 ZIP，在解压目录中打开 `Craftmine World.exe`。选择 **Godot 3D** 或 **Web 世界**；系统会准备这个主世界，随后进入。重复进入同一个入口会继续原世界。

基础世界可以在未配置模型账号时进入。需要对话创作时，在设置中配置自己的模型与账号。保留自己选择的模型和思考强度；全自动创作使用 Auto 权限。

世界准备中会显示实际准备状态。可以取消准备并保留世界；再次进入会继续准备或重试原世界。不要因为等待而反复解压到不同目录或删除个人存档。

## 在世界中创造

- WASD 移动，E 与世界中的交互物互动。
- F2 打开对话，描述你希望发生的变化，例如“建一个能走进去的小屋”或“让这把枪能够拾取和使用”。
- Shift+F2 展开对话；Esc 收起对话，再按 Esc 打开暂停菜单。
- 全自动模式会执行允许的项目修改、检查与放入步骤。对话中的完成文字不替代世界的实际更新状态。
- 制作过程中输入的下一句话和附件会保留。关闭对话不会等同于取消制作。

## 保存、切换与继续

Esc 暂停菜单提供继续游玩、切换世界、设置、保存并退出。切换入口仍然只有这两个主世界，两者分别保留内容、进度与对话。

保存退出时等待保存过程完成。如果保存失败，程序保留当前世界并显示可重试原因。再次打开会恢复上次选择及已确认的进度。

制作中退出后，已经写入的修改和部分回复会保留为未完成状态。返回原世界的对话，发送“继续刚才的修改”或补充具体问题，会接续原草稿。未完成的修改不会冒充正式可玩的结果。

## 找回以前的作品

打开设置中的 **高级存档管理**，可以访问旧作品、存档和未完成世界。打开旧作品不会将它强行转换成另一种世界。旧作品不需要先删除才能使用双世界入口。

需要报告问题时，保留正在运行的 EXE 所在目录、可见提示和截图。新用户测试应使用独立测试资料目录，不要通过删除个人存档模拟第一次打开。

本说明描述产品操作；具体发行包的通过项、失败项和已知限制以该包的验收报告为准。
