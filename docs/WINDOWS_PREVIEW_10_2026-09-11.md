# Windows preview.10 构建与试玩说明

用户已授权本轮提交、推送、清理工作树并生成新 Windows 成品。版本为 0.14.4-preview.10，包含已完成的沉浸式造物 Alpha。

从干净提交运行 desktop/build-client.ps1 -Installer：重编译 Rust 核心和可信 broker，刷新运行资源、桌面与插件，生成源码归档、NSIS 安装包和逐文件哈希证据。安装包会解出实际载荷，与同批程序目录逐项核对；便携 ZIP 从这批封存材料生成。

交付目录为 D:/Craftmine-World-preview.10，最终提交、安装包 SHA-256、构建与成品验收结果写入该目录的中文交付记录。构建不会执行安装程序或替换正在使用的安装。

试玩流程：新建空白 3D 造物世界 → 在这里放树 → 选中树并放大 → 有限复制 → 新增机关开门 → 检查采用 → 保存退出 → 重开继续创造。打字和已有语音入口共用草稿。具体使用与升级说明见 desktop/windows-USER_GUIDE.zh-CN.md。

已有 8 环节 Alpha 自动验收证据继续保留。本轮另外验证实际封装产物和启动隔离；真实玩家手感、物理麦克风及真实模型首轮成功率由实际测试独立记录。全部自动测试禁止真实输入、Pointer Lock 和置前窗口。
