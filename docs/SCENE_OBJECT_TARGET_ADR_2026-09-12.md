# ADR：普通场景对象的当前实例引用

日期：2026-09-12。状态：有限实现，通用源码修改上下文。

## 决策

增加独立 `sceneObjectTarget`，让具有碰撞体的普通 GDScript 场景对象可以随玩家请求冻结。保留 `creation.json`、五类 `creation_operation` 和结构化愿望检查合同。普通节点不变成结构化实体，不自动取得直接编辑或安全采用资格。

固定 adapter 从实际物理射线取得节点引用，覆盖全部碰撞层，排除玩家及其子树碰撞体。已有结构化实体、地面和边界的同一命中继续沿原路径。若更近的普通对象遮住后方地面或树，本次捕获只将普通对象用于源码上下文，隐藏后方结构化目标，避免把“这个”改成后面的对象。显式最近结果选择仍优先于当前射线。

引用字段包括引擎对象 ID 字符串、世界根相对节点路径、真实节点类型、命中点及法线、最多四层祖先。脚本和场景路径只有出现在当前正式构建的源码清单中才会进入宿主上下文；其余返回 null。文件、名称等项目文字是数据，不是指令或语义验收证据。

## 新鲜度与边界

- 最近最多 32 个实际命中碰撞体由固定 adapter 保存 WeakRef；每次既有 `observe-envelope` 重新检查存活节点。重复采样同一对象不反复插入。不新增任意节点访问或任意方法调用 RPC。
- 宿主核对世界、构建、运行实例、源码 revision 与 manifestHash；普通对象在捕获、提交验证、绑定 turn 前均重新采样。采样时间必须新鲜，旧捕获时间不冒充刷新时间。
- 相机移开不改变冻结目标。改名后仍匹配原 ObjectID，保留原 `nodePath`，另存 `sceneObjectLive.currentNodePath` 及新 `sampledAt`。删除、同路径替换、引用被淘汰、冷重开或换构建均要求重新捕获。
- 若绑定的源码路径或最多四层祖先身份发生变化，同样要求重新捕获；只改名且节点／来源保持的情况仍可继续。不能仅因叶子节点存活，就把原先挂在其他父节点上的脚本当成本次对象的当前来源。
- 身份范围仅为当前运行实例。节点路径、ObjectID、共享脚本均不是跨重开的逻辑对象身份。多实例共享脚本时源码修改可能影响多个实例，模型必须先检查实际源码。
- 模型不能通过 renderer 提交节点 ID 来替换目标；请求仍只有宿主生成的 captureId。节点 metadata 不进入新身份合同，不认定权限、实体 ID 或通过结果。
- `project_inspect` 显示冻结节点及最后一次绑定时确认的当前路径；这不是持续追踪流，也不保证之后任意时刻对象不会删除。正式采用和源码修改仍走现有检查／版本流程。

## 未覆盖范围

本轮实际通过并采用的第二次 PET01 狗由 Node3D 和 MeshInstance3D 构成，没有碰撞体。**本实现不能直接瞄准该样本，不能宣称已经解决它的连续修改。** 没有为测试对象补碰撞，也没有加入狗专用工具。后续需单独设计有限几何拾取或通用场景对象列表。

旧构建只有旧 adapter 时继续保留原目标行为；本能力需要包含新版固定 adapter 的实际构建。通用节点跨重开持久身份、祖先语义根判断、视觉品种判读均未实现。
