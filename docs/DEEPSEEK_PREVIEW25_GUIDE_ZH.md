# DeepSeek 创作测试版使用说明

完整解压 Windows 测试包后使用启动脚本。已有 preview23 存档的玩家可使用包内
`docs/CONTINUE-PREVIEW23.cmd` 继续原世界；先正常退出旧版应用再启动。
根目录 `START-PLAYER-PREVIEW.cmd` 使用独立的新测试档案。

## 模型配置

DeepSeek V4.1 Flash 的官方 API 名称是 `deepseek-flash`，端点为
`https://api.deepseek.com/`。在应用里填写自己的 API Key，不要把密钥发到世界对话中。
版本名称和 API 名称的依据：<https://deepseek.com/news/deepseek-v4-1-flash/>。

按最新要求使用 1,000,000 上下文、384,000 最大输出、最高思考配置。
384K 是单次输出上限；请求还要为它预留空间，因此 1M 窗口不等于能同时放入
1M 历史再输出 384K。当前配置扣除输出和工具余量后，输入容量约 614K，约 522K
估算输入开始整理。模型实际输出短于上限很正常。

创作卡片里的“总 Token”是整轮多次请求的累计用量；底部上下文比例是上次请求的
窗口用量。两者不能直接比较，也不能用累计 100 万判断单次上下文已满。

## 恢复旧任务

旧任务如果显示 `COMPACTION_BUDGET_EXHAUSTED`，使用恢复按钮
“解除本地次数与时长限制后继续”。它保留草稿、原用量和失败记录，再继续当前世界。
新普通创作任务不再默认套用 8 次压缩、80 次请求或整轮 30 分钟限制。
玩家自己设置的累计 token 预算仍保留。

“全自动”模式下，恢复时按当前世界与权限重新建立创作绑定，检查后自动更新世界。
如果选择手动确认，仍需按结果卡片先预览再应用。

本次修复的真实测试结果、失败记录及验证范围见
[测试记录](DEEPSEEK_PLAYER_TEST_2026-09-14.md)。美术效果和连续真人操控手感仍需玩家体验。
