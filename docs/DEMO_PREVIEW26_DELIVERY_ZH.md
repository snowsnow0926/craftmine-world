# Demo preview26 使用说明

Windows x64 免安装版。完整解压到新目录后，双击根目录 `START-PLAYER-PREVIEW.cmd`。请先正常关闭旧版应用。

默认启动使用独立的 preview26 资料目录。要继续原 preview23 的世界、会话和模型配置，可使用 `docs/CONTINUE-PREVIEW23.cmd`；要继续 preview25，则使用 `docs/CONTINUE-PREVIEW25.cmd`。一次只使用一种启动方式。

## 试玩与录制

- 内置示例：入口“示例世界”直接创建个人副本，无需连接 AI 即可游玩。
- 宣传片素材：在“我的模板”导入 `examples` 中的 ZIP，再创建独立世界；“示例世界”也提供了前往导入的入口。
- 模板包含作者保存时的位置、探索和互动进度。双狗寻宝模板的宝物已经收集完毕，录制新的寻宝过程请使用另一个起点。
- 新 AI 创作需要配置自己的服务。DeepSeek 设置见 `docs/DEEPSEEK-MODEL.zh-CN.md`；包内不包含 API Key 或私人测试档案。
- 操作和录制顺序分别见 `docs/PLAYER-GUIDE.zh-CN.md`、`docs/CITY-PLAY-GUIDE.zh-CN.md` 和 `docs/RECORDING-GUIDE.zh-CN.md`。

## 本轮修复

- 模板导入后刷新列表；空搜索提示正确；失败后的重试继续原创建操作，避免重复世界。
- 切换连接后，旧导入和查询结果不再覆盖新选择。
- 创作结果区分自动检查、应用和实际试玩；失败时显示简短说明，原始错误保留在详情。
- 刷新时保留当前结果；确认最新状态之前不能使用旧的采用按钮。
- 宠物 v3/v4 的直接复用、组合与提案安装采用一致的世界范围配置规则；旧版素材保留兼容行为和范围提示。
- 新增宠物 v4，修复连续转向导致缩放误差积累、进而被存档检查拒绝的问题。素材库提供新版，旧世界和固定配方不会自动升级。
- 组合工具接受目录中已经存在的第 3 版方案。
- 双狗城市的修复通过当前世界自己的脚本实现，已发布素材和原失败模板保持原样。修复模板的实际验证结果见随包复盘记录。

## 验证范围

自动检查通过表示对应检查和版本处理成功。跟随、战斗、导航等玩法仍应在实际场景中试玩；任意新创意并非都已验证。原 preview25 包可保留用于对照。

遇到问题，请保留世界名称、原始指令、错误详情及前后画面。不要为了排错先删除原世界或资料目录。
