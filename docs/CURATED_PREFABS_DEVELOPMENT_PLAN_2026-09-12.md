# 可复用素材与预制组件开发计划（2026-09-12）

## 目标

根据玩家看完六组实机图后的要求，转向建设经过验证、能被游戏内 agent 找到并实际放入世界的素材与组件。减少每次从基础几何体重新写造型，让同样的自然语言愿望更快得到清晰、协调的画面。素材存在、工具可调用、真正进入世界分别验收，不以目录文件数量代替效果。

## 首批工作

1. **自然环境与静态物件。** 精选树木、花草、岩石、城墙/塔楼等可组合模型；保留原始文件、固定版本、作者和许可。先做少量能在当前 Compatibility/Web 成品真实显示的资源，而非堆满无法使用的大库。
2. **通用画面预设。** 可选的自然日光、天空、草土与石材地面，改善目前亮青色平地和缺少层次的问题。通过明确引用接入，保留昼夜与存档逻辑，不覆盖玩家已创建的世界。
3. **agent 发现与复用。** 沿用现有资产目录和 Godot 源码包安装、检查、采用流程，补齐实际断开的模型入口；目录含中文用途、尺寸/锚点、资源依赖和适用范围。模型能选取和组合，并继续修改。
4. **真实示例验收。** 独立世界组成树林小径与建筑角落，验证素材加载、材质、碰撞边界、保存重开、两个实例独立修改；出原始实机对比图。随后用实际玩家模型配置输入自然愿望，确认模型真的复用了资源。

## 内容来源与质量要求

优先选统一风格、许可允许随成品分发的现成资源，以及项目自己的普通 Godot 组件。首批候选为 [Kenney Nature Kit](https://kenney.nl/assets/nature-kit) 与 [Castle Kit](https://kenney.nl/assets/castle-kit)，官方页面均标明 CC0；下载包内许可和每个入选文件哈希仍需登记。不得把原始模型、拥有碰撞的物件、含状态的玩法模块混成同一种能力。

动物、角色动画、战斗、门与宝箱、雨等组件后续按实际缺口补齐。静态模型不冒充可驾驶飞机、可战斗怪物或完整城市；玩法组件需要独立行为与保存验收。

## 验收与当前状态

所有测试保持独立后台，不操作用户鼠标键盘或浏览器。真实模型跟进按玩家实际配置和原意进行，不额外添加评测 token、次数或整轮时间上限。旧六组作品与报告保留作对照，不手改它们来伪装模型能力提升。

本文件建立时：已有资产检索、预览和 Godot 源码包安装基础；现代资源目录与模型旧 package 提案存在接线差异，正在核实修复。首批素材内容、环境预设、模型入口分路并行，最终由总控集成到同一成品验证。

## 首批推进记录

已形成 16 件静态物件、自然环境模块和一个“林间入口”组合场景，共 18 个既有格式源码包。组合场景包含 7 棵树及成簇地被、石块、朝向校正的门洞；保持中心通道，自身不替换用户的光照。

现代素材检索、精确版本读取、冻结安装提案、指定单实例位置、正常检查与采用已接通。真实 Rust 预检覆盖全部 18 包和一次重复安装；这是安装事务证据，不代替引擎验收。

在冻结成品 `bafb5b18` 中，原五组件演示已通过实际采用和保存冷重开。期间发现并修复预制场景类型解析、受控 GLB 导入设置及安装请求等待时间的问题，原失败记录保留，城墙通过重检已有源码恢复，没有重复安装。旧白狗世界也已通过正常观察组件升级，普通作品源码和完整进度保持。

下一项验收是组合场景在最终成品中的真实画面，以及普通模型按自然愿望复用已安装橡树。模型尚未完成这条验收，不能把开发者布置的示例当成 agent 自主结果。
