# 两条试玩问题修复版：使用说明

此版本继续使用原 PI Desktop 界面，修复小狗素材安装、检查与采用状态，以及网页世界
使用 Codex 的创作与评审通路。最终是否通过真实模型和 Windows 客户端验证，以随交付
给出的验收记录为准。

## 继续已有的试玩世界

先保存并关闭旧 preview.23 应用。完整解压新包，运行 `docs/CONTINUE-PREVIEW23.cmd`。
这个入口使用你原来的 preview.23 数据目录，保留世界、素材、聊天和设置。
不要同时使用两个版本打开同一档案；不要删除旧目录来解决显示问题。

新包根目录的 `START-PLAYER-PREVIEW.cmd` 使用独立的 preview.24 档案，适合从头测试。
在这个入口看不到旧世界，并不代表旧世界丢失。旧版本和原始问题证据继续保留。

## 再添加一只小狗

打开“白色博美与巨兽试炼”的自己的副本，选择创作和全自动模式，在原对话发送
“再给我生成一只小狗”。兼容素材可由 Agent 直接安装到当前草稿，并继续真实检查；
检查完成后由应用按原有全自动设置采用。原有狗与其他玩法应保留。

“安装提案”仍表示等待玩家确认；“检查通过”表示候选可应用；只有读取到真实采用
记录才显示“已加入世界”。普通手动模式继续保留提案、预览和确认操作。素材卡片会
自动刷新采用结果。发生错误时保留原世界和草稿，不需要重复安装同一素材来刷新画面。

## 网页世界创建内容

在新建世界时选择网页世界，打开创作对话，核对当前选中的后端和模型后发送原始需求。
Codex 通过网页世界自己的草稿、验证与评审流程工作；不会偷偷更换成另一个模型，
也不会把已有网页世界转换成 Godot 世界。检查和评审完成后按界面流程预览、应用，
再保存退出并重新打开验证。

仍可按个人选择使用其他已配置后端；本轮错误发生后的 Deepseek 尝试与 Codex 验收
是不同记录，互不替代。
