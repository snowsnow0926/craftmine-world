# CN3 中文颜色与尺寸愿望开发记录

日期：2026-09-11。基线：`fa9f7247`。对应《连续造物与 preview.11 成品开发计划》CN3。

## 实现

新增纯文字有限解析器，支持九种确定颜色及六位十六进制色、明确倍数、同一对象颜色和尺寸的组合，以及带属性的单物件放置。宿主继续从冻结目标计算要求，不接受模型替换目标或要求。颜色词的十六进制值同步写入创作指南。

每个请求必须完整符合支持语法。属性重复、方向矛盾、模糊程度、不同对象混合或未知附加要求均保留待核验。结果尺度须满足现有结构化操作每轴 0.25..4 的限制；历史上能够匹配但实际工具无法执行的超大倍率不再获得可验证状态。原固定采伐、时间、复制、保留进度及副本语句仍通过既有回归。

同对象修改将最终颜色和三轴尺寸写入同一个实体要求；属性放置绑定一个新对象和冻结落点。原对象、其他物件、数量及静态可见／碰撞状态继续受检查，不允许用不同对象分别满足颜色和尺寸。
