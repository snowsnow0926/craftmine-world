# CN4 真实执行器协议回归记录

日期：2026-09-11。生产修复来源：`9b5329b2`；本工作树等价整合提交：`b195972a`。

本轮补充七项直接调用 `createGodotExecutor` 的协议回归，执行完整 claim、导入／导出回执校验、PCK 校验、检查终态、采用回调和持久化路径。不是仅测试状态整理函数。

## 新增覆盖

1. 同一有效回合：在 core 能返回检查通过之前落盘 pending；宿主回调前落盘 applying；真实回调返回后记录 applied。新执行器读取完成回执，不再次调用采用。
2. 无当前回合的 queued 作业经 `reconcile()` 恢复，检查正常通过且保留候选，采用回调次数为 0。
3. applying 文件写好、原子 rename 尚未完成时取消作业，采用回调次数为 0，检查仍通过，回执为 cancelled。
4. 同一持久化窗口停止执行器，停止路径取消并排空作业，采用回调次数为 0，不把取消说成采用成功。
5. core 已提交检查通过，但 finish 回复丢失；仅提交一次 finish，采用回调次数为 0，保留实际候选和 manual／丢回复原因，不误报重启。
6. 宿主已经返回 applied，但最终回执写盘失败；读取结果显示持久化未确认。新执行器读取旧 applying 回执，显示 interrupted，不重新执行采用。
7. 宿主返回手动采用状态时，保留检查通过与候选，明确说明未获自动采用授权。
