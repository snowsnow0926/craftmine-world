# 历史采样器与新场景引用的权限边界

恢复旧世界时仍须运行它原来已采用的源码。旧固定 adapter 会重新采样已有
五类实体，却不认识后加的 `sceneObjectTarget`，可能透传普通世界脚本的
同名字段；因此不能只看 JSON 字段形状就把它当作真实节点身份。

主进程现在从当前随包资源读取五个固定文件的 LF／CRLF 哈希，与正式构建
的完整来源清单匹配后，才接受新普通引用。任一文件缺失、改变或重复都
不能启用该能力。原世界与预算没有被重写，旧采样器仍保留原有结构化路径；
历史导出包的兼容校验不等于获得新观察或交互能力。

19 项目标服务回归通过，包含逐个篡改固定文件、旧三文件加伪造新字段和
无新字段旧世界回退。运行时的来源／实例新鲜度检查继续执行。
