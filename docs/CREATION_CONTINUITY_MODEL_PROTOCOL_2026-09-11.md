# CN5 连续造物真实模型试验冻结协议

本批仅一个开发验证轮次，四个独立档案，每例最多10次请求，总计不超过40次。每例最多10分钟及两次模型修复；未知请求保留预约，不回退预算。旧模型试验与失败记录不变。尚未执行真实请求，本文件不宣称案例通过。

| 案例 | 真实初态 | 冻结原话 |
| --- | --- | --- |
| CM01 | 空白造物世界、真实空地 | 在这里放一棵蓝色的树 |
| CM02 | 经直接操作放置的默认绿树，射线选中 | 把这棵树放大到2倍，并改成蓝色 |
| CM03 | 默认绿树及一个直接复制品，射线仍指原树，最近结果显式选副本 | 把这个对象改成红色，其他东西保持原样 |
| CM04 | 独立默认绿树，射线选中 | 这棵树的颜色改成#88bb44，其他东西保持原样 |

初态只走真实无模型放置/复制，不预写目标答案。模型使用项目已授权的DeepSeek配置、deepseek-flash/high；实际构建就绪后冻结源码、main、core、guidance、引擎和案例身份。每个profile、轮次及案例都持久登记，不能重放已尝试案例或重建预算。产品网络请求前真实reserve，读取实际会话核对原话/消息ID/回合及修复次数；历史不可确认时拒绝继续，不把查询失败当作零次修复。

入口 `node tests/creation-continuity-model-native.mjs --plan` 不调用模型。`--freeze <绝对test-results目录>` 固定输入与构建；正式执行需要显式的 `CRAFTMINE_CREATION_CONTINUITY_EVAL=1`、本地配置路径和 `--run --manifest <已冻结文件>`。测试目录应较短，以满足真实broker任务路径限制。旧suite的40次语义保持不变。

验收读取真实颜色、尺寸、对象身份、位置、碰撞、冻结愿望哈希、已采用构建及冷重开完整进度。模型文字不作为成功证据，失败和补验单列；这些表达均参与开发，不称未见保留集或总体成功率。没有物理输入、麦克风或用户安装操作。

8项纯约束及结果判定测试通过，覆盖预算防重放、实际reserve先落盘、上下文/历史错误、两次修复上限与成功轮询不计修复、原话身份、完整重开状态。真实模型和包内验收在总控确认构建后执行。
