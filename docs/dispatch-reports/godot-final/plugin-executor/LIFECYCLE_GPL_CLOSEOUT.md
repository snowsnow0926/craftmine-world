# Executor lifecycle and independent GPL full text

The executor invalidates its startup generation synchronously when stop begins. Stop waits for the existing bounded startup/preflight/registration promise before recovering task processes, draining jobs and revoking registration. An obsolete startup cannot register after its preflight or promote jobs. If registration was already in flight, its successful reply is retained for stop to revoke. Starts requested during stop wait for the stop barrier; simultaneous callers share the next startup. This change is confined to executor lifecycle code and does not alter engine policy or broker trust.

Two protocol regressions drive the actual executor with the existing scripted broker child and an in-memory core. One stops during the broker preflight and requires the child to exit without registration. The other holds a registration RPC, starts stop/restart concurrently, then requires register/revoke/register order. These are supervisor race tests, not a new native sandbox or real Godot acceptance claim. Local execution was refused at child `spawn` with EPERM. The main agent subsequently ran the exact tests under its existing permissions: **2/2 passed**, zero failures/skips; raw output is `test-results/final-executor-stop-races.log` in this worktree.

The already-retrieved official GNU GPL-3 text is copied byte-for-byte from `desktop/delivery/licensing/texts/LICENSE-GPL-3.0.txt` to `resources/licenses/gpl/GPL-3.0.txt`. Its immutable inventory pin is 35,149 bytes, SHA-256 `3972dc9744f6499f0f9b2dbf76696f2ae7ad8af9b23dde66d6af86c9dfb36986`; provenance is the existing GNU URL in `texts/SOURCES.json`. The production runtime stage and package verifier include this dedicated managed directory. K checks the independent full text rather than requiring the upstream LGPL supplement itself to contain both licences. Missing, substituted and modified copies fail; no rights, licence declarations or approval status change.
