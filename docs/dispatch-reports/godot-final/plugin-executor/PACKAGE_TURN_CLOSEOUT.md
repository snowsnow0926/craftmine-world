# Package installation task lifecycle

The product binding previously sent `turn.begin` directly to Rust, where that method does not exist. It now calls the real private host router, which creates the workspace and records the request. Failures after workspace creation end the owned turn. Branch identity and its head come from the trusted project index and content branch list; the branch is carried through source reads, atomic apply and check requests. The package UI currently has no branch selector, so the index's existing default remains authoritative.

The installer explicitly tracks only turns it owns. Invalid ZIP, source/plan/transaction failures close those turns. A blocked check returns the saved-source receipt and closes the source-edit turn; replay returns the same blocked receipt, and a new check uses the regular history task. Queued jobs keep their turns until core status is passed, failed, cancelled or interrupted. A host monitor then ends the turn. Shutdown and profile restore drain installation requests, confirm cancellation of remaining jobs, and finish owned turns before the core switches or exits. Unknown finalization errors remain retryable at shutdown rather than being silently discarded.
