2. 安装器规划器首次测试失败（2 项）
-----------------------------------
cargo test -p craftmine-core
test result: FAILED. 130 passed; 2 failed

(a) library::installer::tests::plans_dependencies_first_and_allocates_new_identity
    left:  ["recipe@1","stone@1"]   right: ["recipe@1"]
    原因：plan.lock.direct 用了全部传入资源，而不是解析后的根。
    处理：direct = roots。

(b) library::installer::tests::missing_dependency_and_cycle_are_refused_without_a_plan
    Error: PACKAGE_ROOT_REQUIRED
    原因：a↔b 互相依赖时没有任何入度为 0 的根，先触发了“无根”检查，
    掩盖了真正的环。
    处理：根集为空时改为从全部条目开始遍历，让 PACKAGE_DEPENDENCY_CYCLE
    先被报出。

修正后：test result: ok. 132 passed; 0 failed; 1 ignored。
