## 3. G 修复的跨组问题

- JSON 转义导致最终请求大于前置预算：修复完整载荷保守估计，未取消最终预算门槛。
- 库中新增素材/扩展在继续编辑、编译或应用时丢失：所有步骤保持相同固定依赖，拒绝内容冲突。
- UI 切换世界错误地使已绑定任务的记忆上下文读取失败：任务事实仍属于原世界，选中对象在不同世界时失效，不重定向任务。
- 短任务结束后的库/记忆重试：历史精确回执核对先于新建轮次；不同原文同 ID 拒绝，旧不可核实记忆回执拒绝冒认。
- 恢复提交成功但模型启动失败：先写明确 interrupt，再结束 PI turn；草稿、原账本、未知请求预留与恢复入口保持。G 跨真实 Rust/工作台的失败注入测试覆盖该顺序。
- 手动压缩取消原任务检查：只读维护上下文允许摘要预约和压缩计数，原 draft/check/review/owner 保持；无世界普通会话不创建世界草稿。
- 真实模型错误评审 JSON：第一次坏结果与用量先落盘，最多一次格式修正请求；第二次错误停止；严格字段、断言执行和冻结回归没有放宽。
- 原生离屏首帧过早采样：只有空帧情况下进行有界重绘/等待，仍要求实际非空世界画面。
