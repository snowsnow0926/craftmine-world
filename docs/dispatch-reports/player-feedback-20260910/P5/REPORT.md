基线为 eae2799，DTO 合同来自 P4 的 9491db0（集成树中为 eb12a72）。本提交负责真实 React 显示、只读 IPC/API 和版本入口；P4 的实际调用事件记录及 Main drain 接线在后续集成提交完成，本报告不把它们算已验收。

本次操作显示总 Token、TPS、任务耗时和实际模型列表；明细展示输入、输出、缓存、推理和各模型用量。数据直接读取宿主按持久 turn 聚合的 DTO，通过当前 session/message 查找，缺失显示“未报告/—”，部分数据明确标记；没有字符估算或用当前输入框型号顶替历史型号。运行中串行刷新，停止后有限重读，旧会话响应和身份错误不能污染新任务。

左下角版本改为普通文字，取宿主返回的实际版本。移除了此入口的 updater、更新提示点及设置跳转，保留其他设置能力与上游许可证。用户称链接为 PI 桌面版；源码中原路径是 updater，不将未证实的直接外链当作已复现事实。
