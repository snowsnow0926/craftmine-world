# Read-only actual metrics replay

`tests/player-feedback/P8/metrics-replay-native.mjs` selects only the existing hammer session from the owned V35GyJ test profile. It reuses that profile in place under its original marker and saves fresh stdout/stderr/report files in a separate ignored directory. No relay is started, no authorized configuration file is read and no submit/abort/model IPC is admitted. Reopen selects an already configured session with submitted=true; the required proxy metadata is an inert loopback placeholder, not a network service.

The runner verifies a clean expected source and every packaged identity through inspectParameterPackage. Before and after it compares original report/upstream evidence hashes, exact per-turn stored model observations and the shared sixteen-admission journal. It requires one terminal error/partial card with 285458 tokens, exact requested model and 299.7 partial TPS. Original transcript/compactions and formal saved progress must match. Internal app append logs are described by before/after hashes; original evidence reports are not written. A strict owned exit remains required. This proves new-package presentation of real historical metrics only, never a new model task or successful hammer creation.

The external runner requires CRAFTMINE_P8_REPLAY_APPROVED_COMMIT and CRAFTMINE_P8_REPLAY_RUNNER_SHA. Pass the standard --source-root, --deps-app, --packaged-root, --expected-commit and --expected-build-manifest-sha256 options. The original owned profile path is fixed by replay-contract.mjs; arbitrary paths or RPCs are not accepted. Two finite command-contract tests and JavaScript syntax validation passed before any launch.
