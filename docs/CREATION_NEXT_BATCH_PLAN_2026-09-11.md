# 造物世界下一批实施计划：愿望验收、编辑体验与真实模型可靠性

版本：1.0；日期：2026-09-11；源码基线：c1660f12；已交付版本：Windows 0.14.4-preview.10。

## 目标与执行范围

让玩家的愿望获得可解释、可复核的结果：提交文字或中文语音 → 固定真实目标 → 创建或修改 → 验证要求 → 采用 → 调整、删除或撤销 → 保存重开继续创造。延续既有 3D 造物世界、可信宿主、源码事务、候选与进度迁移，不重新实现已完成的全屏、版本文字、任务用量与历史恢复。

本轮使用 Codex 子 agent、独立分支和工作树并行开发，总控统一接口、依赖和验收。开发记录使用中文。用户要求将本计划设为 Goal 持续执行；只有计划必需开发与验证均完成才结束，环境无法完成的验证必须明确留为未验证，不改名计为通过。

## 工作包与完成标准

| 编号 | 工作 | 完成标准 |
| --- | --- | --- |
| NB0 基线与追踪 | 本计划、机器状态、preview.10 交付与反馈结案映射、隔离依赖 | 原始反馈保留；区分已实现、自动验证、真人复验；源码与安装包身份可追溯 |
| NB1 愿望结果检查 | 宿主管理的造物要求；真实候选对象、位置、尺寸、数量与机关步骤；需求证据用于结果与自动采用 | 有界受支持愿望能从提交目标冻结要求；错误对象/尺寸/数量/无条件开门的可运行候选不能算愿望通过；未知玩法明确待验证；不能让模型自行降低检查要求 |
| NB2 常用编辑 | 名称和目标高亮、尺寸/颜色直接调整、删除及操作级撤销，复用现有写入/检查/采用 | 常规参数修改不需要模型调用；取消不写入；稳定对象身份；依赖冲突可解释；撤销不重置玩家位置、背包或已领奖历史；重开一致 |
| NB3 中文语音与状态 | 正确匹配识别语言、选择/重检、缺引擎说明；轻量面板显示检查、采用、失败与恢复结果 | 不静默落到其他语言识别器；转写可编辑；任务收起/重开状态不丢；真实麦克风另列 |
| NB4 真实模型与计时 | 原始愿望到实际工具链的评测入口，预算、分类与分阶段耗时；现有用量账本复用 | 原有 CA01–CA07 加表达变体与非预置行为，首轮小样本基线；首次成功/自主修复/人工介入/失败/环境阻塞分列；真实模型请求不能由脚本预写答案替代；费用未知不编造 |
| NB5 按数据修复与优化 | 根据实际错误修复指导/有界恢复；记录索引读取、修改、导入、导出、检查、采用耗时；同轮修改合并检查 | 必需身份/CAS/进度检查保留；无效目标重新捕获、丢回复查原回执、代码错误才进入修复；优化必须有同条件前后证据，否则只交付计时与正确合批 |
| NB6 交付复验 | 构建、现有功能回归、状态与原始证据归档；检查可用的隔离 Windows 生命周期环境 | 同一源码的真实 Godot/core/宿主/UI 集成通过；干净 Windows 环境可用时执行安装/升级/卸载与旧存档迁移，不在个人安装上冒充；真实玩家与麦克风保留独立验收 |
| NB7 集成收尾 | 中文开发报告、机器状态、统一验证入口、提交与本地合并 | 变更有证据，失败不隐去，源代码与记录可审阅；完成本轮工作树清理，保留其他任务和用户数据 |

## 执行顺序与接口

NB0 后并行 NB1、NB2、NB3；总控同步推进 NB4 的真实请求入口、NB5 计时和 NB0 状态。NB1 的要求固定在宿主接受用户请求/直接编辑之时，绑定目标和版本，模型只能消费；NB2 的 UI 编辑使用同一源码和候选事务，不绕开进度保护。三路接口稳定后合入总控工作树，执行真实集成与模型小样本，再按发现修复并完成 NB6–NB7。

第一轮模型试验是探索基线：优先复用用户已配置的模型，以独立测试档案和固定请求运行；最多 10 个案例、每例最多 3 次修复及 10 分钟、总模型请求最多 40 次，记录实际输入/输出用量。没有可用配置时先完成入口与验证，明确列出所缺配置；不购买额度、不泄露凭据、不静默改供应商。不得将无模型夹具计入真实模型成功率。

## 集成故事及负例

1. 空白造物世界中提交“在这里放一棵树”，检查对象种类、实际位置与碰撞。
2. 指向树并放大，核对同一对象的实际尺寸；通过属性面板再改颜色/大小，不调用模型。
3. 删除或撤销当前操作，确认已有背包、位置、宝箱领取历史不倒退；引用对象时明确冲突。
4. 新增普通脚本行为（优先“树被砍后掉木头并延时生长”），与预置顺序门样例分开；真实运行、保存中间状态、重开继续。
5. 错误对象、尺寸不符、门提前打开、无中文识别器、过期目标、丢回包、编译失败、取消、采用失败均有准确结果和恢复路径。
6. 收起面板后能看到最终采用或失败结果；重新打开草稿和目标不串任务。

## 边界与测试纪律

所有自动验证使用独立数据目录、headless/offscreen、不可聚焦窗口；不发送真实鼠标键盘、不申请 Pointer Lock、不置前，不操作用户浏览器。历史输入测试 tests/browser.mjs、tests/modules-browser.mjs 不运行。UI 自动测试通过脚本与实际接口完成。

未获得真实玩家/物理麦克风/干净 Windows 环境证据时，这些项目保留“待外部验收”，不影响继续完成可独立推进的实现，但不宣称已通过。大规模模板扩充、自动思考强度路由、全面热更新、多人/社区/云端不纳入本轮实现。

本轮用户授权开发与本地集成；远端推送和替换正在使用的安装不作为本计划的隐含收尾动作。
