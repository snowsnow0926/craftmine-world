## 实现与协作

总控工作树为 `D:/Craftmine Worktrees/product-completion-20260914`，分支 `codex/product-completion-20260914`。总控负责第 2 项、接口整合、普通玩家的真实 Agent 验收、最终 Windows 成品和本地合并。三个 Codex 子 agent 分别在自己的工作树负责玩法组合、可视化编辑以及玩家接入／分享。

先复用已有接口并补齐缺口。世界与持久业务数据由 Rust 管理；前端不持有原生文件路径、任意 RPC 或执行权限。现有不可变素材版本、检查与采用事务、存档和世界归属验证继续有效。Agent 提出的计划和“完成”描述不能自行变成已验证的玩法证据。

代码、接口规范、ADR 和用例同步提交；玩家方案与交付说明使用中文。公共注册位置由总控集成，避免各分支覆盖其他功能。依赖独立安装或复制，不用跨工作树目录链接；共享构建缓存不允许多个进程并行写入。

## 联合验证与交付

使用独立后台客户端和独立档案，禁止真实鼠标键盘、焦点抢占和 Pointer Lock，不运行历史输入模拟脚本。普通玩家 Agent 验收先核对实际模型与思考强度，沿用 `gpt-6-astra / xhigh`，不另加 token、调用次数或整轮时长上限。澄清按原始玩法目标回答，失败和中断照实保留。

验收依次覆盖：原有直接素材与世界回归 → 组合配置及真实 Agent 制作 → 连续修改、预览调整与保存重开 → 独立档案导入游玩 → 问题反馈导出／导入 → 原对话修复和再次交付。自动化结果与真人对玩法、美术和手感的认可分开记录。

最终从干净的集成提交构建下一版 Windows 文件夹及 ZIP，保留对应源码、第三方说明、实际文件校验与成品测试。完成后合入本地 `main`，归档证据，按归属安全清理已合并工作树。远程 GitHub 发布、托管、账号代登录和对外发送消息不在本轮自动执行范围；不修改既有 preview.22 及已认可世界。

外部干净 Windows 与真实参与者仍需要实际环境与参与者；本轮完成相应软件和材料，不虚构这类验证结果。
