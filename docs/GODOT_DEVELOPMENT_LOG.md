3D 验收看到真正的中心准星，枪挂在相机下，切剑后图像与攻击状态同步；实际射线将目标血量从 50 改为 38、弹药从 6 改为 5。重新构建 GDScript，将伤害 12 改为 7后，继续从原进度攻击得到血量 31、弹药 4。俯视样本通过物理移动进入商店，并检查金币/物品变化。坏状态在任何赋值前被拒绝，同一运行器仍能继续返回快照。

持久化验收包括关闭并重启整个独立浏览器进程；同一来源、同一底座的不同 worldId 也使用不同存档路径。并发购买、保存、退出按顺序完成。生产中稳定的逐世界来源、主机进度事务、崩溃/配额/写入失败仍未验收。这里没有把“FileAccess 写入成功”单独当作耐久提交证明。

选型改为同版本 **多线程 Web 候选**。单线程模板的退出任务组错误被保留；没有屏蔽它来取得通过。多线程页面补齐跨源隔离与资源策略后，在同一套验收中正常退出。详细原因、测量和边界见[选型记录](GODOT_INTEGRATION_DECISION.md)。

本轮独立审查发现并修复了存档没有包含世界身份、异常响应可能悬挂、保存与退出竞态及坏存档可能部分赋值的问题。该审查与 Rust 隔离原型由一个子 Agent 在明确的文件范围内协作；主线程负责实际 Web 验证、审查及集成。
