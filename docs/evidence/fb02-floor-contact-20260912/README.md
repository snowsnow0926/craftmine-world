# FB02 地面接触与存档恢复证据

这些报告保留运行器原始字节，`summary.json` 记录来源、长度和 SHA-256；Git 禁止对本目录自动转换换行。

- `legacy-failure-report.json`：旧保护器在普通模型作品的引擎玩法验证所记录的坐标 `y=0.898971319198608` 拒绝恢复。原生接触点只在胶囊底极点，分离方向 `[0,1,0]`，深度 `0.00102865695953369` 米。这不是真人物理输入验收。
- `floor-native-report.json`：当前保护器的 10 个真实 Godot 物理用例。允许上述精确保存位置并完整保留其值；拒绝 1.05 毫米墙体、天花板与斜坡穿透，以及超出数值余量的地面穿透，拒绝后恢复原状态。
- `collision-native-report.json`：当前代码重跑原有 17 个碰撞、形状身份、同步和回滚用例。
- `collision-web-report.json`：当前资源的三个真实 Web 导出及 PCK 文件证明；实际生产 verifier 接受合法候选，拒绝穿透候选并恢复。Web 角色自然行走后 `y` 仍为上述值，销毁并重建运行实例后完整存档一致，未发送输入或请求焦点。

当前实现保持全尺寸胶囊和一毫米普通接触上限；仅真实底极点、近乎垂直向上的平面支撑允许额外 0.1 毫米数值误差。不移动保存坐标，不放宽墙体或斜坡上限。

`tests/godot-agent/module-integration-evidence.test.mjs` 将当前物化资源逐文件绑定本批三个真实 PCK 的 SHA-256。旧 `gu3-gu4-module-integration-20260912` 报告保留其原有版本范围，与当前资源证明分开验证。

范围限制：本批是固定工程场景的真实引擎与运行宿主验证，不包含旧世界维护迁移的 Core 事务，也不作为新的普通模型生成验收。
