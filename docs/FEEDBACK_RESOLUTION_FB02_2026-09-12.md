# FB02 修复进度（2026-09-12）

本文件记录 FB02 真人反馈进入开发后的代码映射和当前状态；原始反馈与截图保持在 `USER_FEEDBACK_BATCH_002_2026-09-12.md`。

## 已修复

### FB02-009：预览副本 `INVALID_GODOT_CANDIDATE_ACTION`

根因是 Godot 候选列表 UI 使用 `candidate.id`，而候选协调器要求稳定的 `candidateId`。列表可能同时带有旧的行 ID 和候选 ID，点击按钮时传错身份就会在 IPC 严格校验处失败。

修复：新增 `godot-candidate-view.mjs`，优先使用 `candidateId`，仅对旧记录回退到 `id`；按钮、DOM 数据属性和预览调用统一使用同一个身份。新增 `tests/godot-candidate-view.test.mjs` 覆盖新旧记录和非法身份。

### FB02-001：Godot 载入黑屏缺少状态

修复了 Godot Web shell 的加载页视觉反馈：加载期间显示高对比度背景、旋转指示器和“正在准备场景和运行资源，请稍候”文字；运行时错误仍会替换成错误信息。世界面板同时增加了加载状态层，便于在原生视图尚未接管前显示状态。

### FB02-003：重启后 F2 快捷键可能未激活

发现沉浸快捷键的激活条件依赖本次渲染会话的 `modeChosen`，已保存为游玩模式时重启仍可能保持关闭。现在持久化的游玩模式会恢复快捷键监听；原有焦点、输入法、重复按键和原生子视图边界保护保持不变。

### FB02-008：工作台内显示生成结果操作

预览控制条现在也会挂载在工作台世界视图中，提供“应用到世界”和“返回原世界”操作。沉浸模式仍会自动打开轻量预览层，工作台模式不会因为轮询到候选而强制弹出沉浸层。

### FB02-007：全自动模式下的内置项目补丁

全局权限模式为“全自动”时，内置工具 `plugin_craftmine_world_godot_project_patch` 现在会忽略旧会话残留的 `ask` 覆盖，直接按全自动执行，不再弹出玩家权限卡。放行范围只包含这个内置 Craftmine 项目补丁工具；其他插件、Shell 和外部工具仍按原权限策略处理。

### FB02-006：第一个世界的地面亮度

已通过附件截图识别到具体对象：左侧当前选中的“第一个世界”，副标题为“Godot · 规划中”，对应 `creation-sandbox` 底座。截图中的浅青色地面来自 `creation_world.gd` 的地面材质与环境光叠加。

已将地面颜色从 `#6e9580` 调整为较深的 `#4f6b5a`，环境光能量从 `0.7` 降到 `0.55`，并同步更新指导目录与源文件哈希。需要重新打包后由真人确认亮度是否舒适。
