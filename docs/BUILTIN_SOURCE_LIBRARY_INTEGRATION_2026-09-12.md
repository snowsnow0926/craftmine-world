# 内置素材入库与自然环境包装（2026-09-12）

首批 16 个 Kenney 自然/城堡静态物件，另加一个项目原创自然环境模块，统一打成现有 `craftmine.package/1` 源码包。未新增另一套可安装包格式。压缩目录约 235 KB，实际大小和每包 SHA 随构建生成。

构建脚本逐项核对原始资源清单、文件字节和许可，调用原包格式的打包/解包校验；成品携带固定包目录。启动时沿现有 `asset.import` 入库，模型的现代素材搜索/读取前也可补齐。已有同版本相同内容直接复用；冲突记录保留，不覆盖；损坏的内置正文先拒绝，不能登记成正常素材。入库不修改任何世界。
