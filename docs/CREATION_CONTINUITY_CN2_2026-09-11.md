# CN2 常用造物开发记录

日期：2026-09-11。基线：`fa9f7247`。所属计划：连续造物与 preview.11。

新增“在此放置”入口，提供树、石头、宝箱、门、标记五种现有对象。放置必须使用当前射线的地面落点，最近对象选择不能冒充落点。默认尺寸 `[1,1,1]`、颜色 `#84A866`、旋转零；采用底座已有默认参数，宝箱奖励一个造物代币，门初始关闭。未提交的取消只关闭面板。

对象编辑面板新增 1–8 个复制及三轴偏移，每轴限制 `[-8,8]`，偏移长度至少 0.5。每个副本相对上一副本继续偏移。复制使用当前已采用的属性，未提交的颜色、尺寸不会混入复制。占用、玩家重叠、边界、对象上限继续由原源码编译器整体检查，失败不提交部分副本。

新增操作复用原耐久操作编号、宿主捕获、源码 CAS、检查、采用和撤销。界面不传目标身份或自由坐标。宿主冻结每个副本的位置、种类、尺寸、颜色、总数及原有物体，无需扩展 Rust 原有特殊“两份复制”要求。放置默认属性也进入实际检查。重复提交、丢回复只读取原操作结果，不制造第二份内容。

已完成验证：

- 源码操作、冻结要求、直接编辑服务与采用守卫：52 项通过。
- 实际 React 回调与隔离 headless 界面：14 项通过，覆盖五种放置、取消、非法复制数量、最近对象拒绝放置、丢回复与双提交。
- TypeScript 全量检查通过；首次检查因共享 SDK 尚未编译报告缺模块，依赖准备完毕后复查通过。

新增 `tests/creation-place-native.mjs`，支持源码客户端及 `--packaged-root <win-unpacked>` 真包 EXE，计划执行五种放置与撤销、最近结果选择、两个副本、单副本改色与撤销、冷重开、零模型用量、实际窗口隔离。此记录写入时尚未运行该原生场景，须由集成后的 CN1/CN2 和最终编译材料执行并保留真实结果。真实鼠标键盘、Pointer Lock、模型请求和安装器均未使用。
