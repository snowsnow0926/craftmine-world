# DeepSeek 造物主多轮实测清单

本清单是待执行方案，不是已通过报告。每个场景约三轮，允许按实际澄清继续对话；不得为了满足轮数而截断任务、缩减玩法或默认选第一项。

## 共同条件

- 使用附件指定的官方 `deepseek-flash`、实际 max 思考；用户新要求的 **1M 上下文**在界面与运行配置中核对具体数值，原 **384000 单次输出**保留。确认修复后实际请求 effort 为 max。记录版本、配置与模型，不记录密钥。
- 独立后台应用和测试资料；不操作用户的鼠标、键盘、前台窗口或浏览器，不申请 Pointer Lock。模型不设额外 token、调用次数或整轮时长预算，保持可取消。
- 每轮保留原始请求、澄清回答、工具失败、实际检查与应用回执、用量、耗时及压缩次数。Agent 说“完成”不能代替画面和实际交互。
- 通过 `input-segment` / `explore` 的现有后台接口执行真实游戏处理器；按生成后的实际操作说明选择键位。输入前后记录同一 world/build/instance 的画面、快照与进度，不写入测试所需的角色位置、收集数或胜利状态。

## 场景 A：宣传城市中的素材复用与连续修改

入口：从普通示例选择器打开 `promo-city` 的个人副本，或使用已保存的“城市飞行与伙伴”对应实际模板。创建前后记录 source/template 身份；原世界不覆盖。先留存城市、已有角色、飞机及任务进度。

| 轮次 | 直接发送的玩家请求 | 操作与客观验收 |
| --- | --- | --- |
| A1 | 在这个城市里做一个“带博美寻宝”的小玩法。优先从素材库复用已有的可爱白色博美和雨天效果；如果当前已经有这只狗，就沿用它。小狗能跟随、等待和被抚摸。放三个走路能到的宝物，靠近按提示键拾取，屏幕显示进度，并能开关下雨。保留整座城市、原来的飞机和其他玩法。 | 核对素材搜索/精确版本与哈希，区分“素材库安装”和“沿用当前源码”，不以一句“已复用”代替证据。实走到一个宝物并拾取；同一宝物不能重复加分。让狗等待、抚摸一次，切换雨天。确认城市及飞机仍在，计数为 1/3。 |
| A2 | 雨太大了，改成小雨，而且默认先不下。寻宝改成四个目标，我刚才捡到的那一个不能重置。小狗别挡在正前方，跟随时待在我右后侧；刚才让它等待，就先继续等待。其他内容保持。 | 改动后仍为 1/4，原宝物保持已收集；默认无雨，开启后可见小雨。狗保留等待状态，重新指令跟随才移动，画面能判断相对站位。确认没有第二个天气控制器叠加或整体场景被重建；保存并冷开后再核对收集与等待状态。 |
| A3 | 再加一只同款的白色博美，叫雪球，第一只保留。两只都要真的在场景里，我能分别让它们跟随、等待和抚摸，不能操作一只却替换掉另一只。保留刚才的寻宝进度和小雨设置。 | 两只狗同屏、身份独立；对一只执行等待/抚摸，另一只的对应状态不被改写。完成剩余三个宝物，进度到 4/4且重复拾取不增长。保存、正常关闭、重新打开：两只仍存在，收集完成及天气设置保留。 |

附加普通 UI 检查，不额外编造模型轮次：通过素材库“保存世界模板”保存当前成果，检查返回的真实 assetId/version/hash；导出后从库创建另一份世界副本并打开。当前产品模板包含保存进度，副本继承已完成进度是预期，不能冒充“全新零进度模板”已支持。比较两份世界 ID 不同、原世界不被覆盖，并确认新副本能继续游玩。

## 场景 B：真正空白世界从零创造可玩关卡

入口：普通“创建空白世界”表单，选择主机报告已交付的 Godot `creation-sandbox` 和空白起点；先截图确认只有底座的基础环境，没有复用完整宣传关卡。世界名可用“风车岛冒险”。

| 轮次 | 直接发送的玩家请求 | 操作与客观验收 |
| --- | --- | --- |
| B1 | 从这个空白世界做一个可玩的风车岛小冒险：有能走过去的桥、岛上的风车和三个能量晶石。玩家靠近按提示键拾取晶石，收齐后风车转起来，终点的门打开并显示通关提示。掉下岛会回到安全出生点，但已经收集的晶石不能丢。我要能实际走、收集、开门，不是只有摆设。 | 玩家能行走过桥；实际拾取第一个晶石到 1/3，终点门仍挡住玩家。主动从边缘掉落，观察回到安全地面且保留 1/3；门不能提前穿过，不能出生即通关。留存晶石的稳定身份。 |
| B2 | 把最后一个晶石搬到桥对岸更显眼的地方。桥上加一道需要按旁边开关才能打开的机关门，并给清楚的提示。刚才已经拿到的晶石保留，出生点和掉落重生也别弄坏。 | 仍为 1/3，移动目标没有被当作全新第四个晶石。玩家在关门时确实受阻，靠近操作开关后门有可见运动并能通过；重新开关不增加收集数。到达移动后的晶石，拾取到 2/3；保存并冷开，进度和机关状态按已声明规则保留。 |
| B3 | 再加一个巡逻的石头守卫。靠近时它会追我，碰到会扣血并有清楚的受击反馈；退回出生点安全区它就不再追。被打倒会重生，但已经收集的晶石不丢。保留桥的机关和收集开终点门的规则。 | 观察巡逻→接近追击→接触扣血→退回安全区停止追击；仅靠源码中存在这些函数不算通过。实际被击倒并重生，仍为 2/3；随后拾取最后一颗，观察风车转动、终点门打开、通关提示。冷开后完成进度保留，角色仍可操控，已有桥机关不失效。 |
