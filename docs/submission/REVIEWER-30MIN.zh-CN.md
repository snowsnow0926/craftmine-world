# 最中幻想：评委试玩路线

这是一条约 **35 分钟实际游玩**的建议路线，利用包内已经制作的世界体验探索、伙伴、驾驶、战斗与保存。导入、首次加载和 AI 生成的等待另计。路线安排不代表已经完成本次提交包的 35 分钟真人连贯验收。

完整解压后运行 `START-PLAYER-PREVIEW.cmd`。在世界入口选择“我的模板” → “导入世界模板 ZIP”，选取下表文件；填“新世界名称”，点击“创建独立世界”。进入后选择“游玩”。每份模板创建独立副本，包含作者发布时的进度。先保存当前世界，再切换下一个。

## 只有 3 分钟时

导入 `examples/deepseek-six-step-playtested.zip`。在树和花草旁移动，按 **3** 使用重剑攻击小怪；按 **2** 换 AK47；按 **H** 进入巨兽试炼，瞄准还击后按 **B** 返回。这份存档呈现的是六次自然语言需求完成后可以继续玩的结果。若要亲自体验创作，再按后文连接 AI。

## 35 分钟路线

| 实际游玩时间 | 世界模板 | 动手目标 |
| --- | --- | --- |
| 0–6 分钟 | `examples/companion-and-rain.zip` | 找到伙伴，按画面提示互动、切换跟随和等待；绕场景走一圈，观察伙伴绕行与雨天环境，再回到起点。 |
| 6–18 分钟 | `examples/city-flight-and-companion.zip` | 用 M 看地图，挑选尚未走过的城区探索；与白色博美“小麦”互动，让它等待后沿城外南侧道路向东到机场。尝试登机、滑行、一次起飞和降落。 |
| 18–30 分钟 | `examples/deepseek-six-step-playtested.zip` | 用重剑迎战小怪，观察距离与耐力；进入巨兽试炼，练习躲避攻击，再尝试步枪瞄准、射击和换弹。可以重复挑战并比较两种武器。 |
| 30–35 分钟 | 继续当前世界 | 返回世界，记录当前位置、弹药及击败记录，保存并重新打开同一世界，确认继续此前进度。然后在场景中继续走动、互动或战斗。 |

若某项挑战尚未完成，可以继续尝试，不必为了计时提前结束。驾驶和战斗难度不适合时，也可将对应时间用于城市探索、伙伴互动及树木编辑；请优先体验自己感兴趣的玩法。

## 城市：探索、伙伴与飞行

WASD 行走，空格跳跃，E 交谈或收集，M 查看地图。靠近小麦并瞄准它，按 E 抚摸；在身边按 H 切换跟随和等待。

此城市模板中三个通航物品已收齐，飞机已解锁，并保留一次起降记录。可以直接体验飞行，不需要寻找已经收走的任务物品。当前机头朝南；登机后先低速转向跑道延伸较长的北端。

靠近停稳的飞机按 E 登机。W 加油门，S 收油，空格刹车；地面滑行时 A/D 或 Q/E 转向。达到画面提示的起飞速度后，短按向下箭头抬头；向上箭头低头。空中 A/D 滚转，Q/E 方向舵，G 起落架，C 切换视角。松开 W 不会自动收油。降落后按 S 收油、空格刹停，再按 Enter 离机。

详细驾驶说明见包内 `docs/CITY-PLAY-GUIDE.zh-CN.md`；其他城市模板的操作以各自画面提示为准。

## 战斗：先小怪，再巨兽

六步战斗模板已击败一只小怪，步枪已换满弹，存档起点处于巨兽试炼之外。它不是新战役，也不会清空已保存的战斗记录。

| 操作 | 本战斗模板按键 |
| --- | --- |
| 行走／转视角 | WASD／方向键 |
| 重剑／AK47 | 3／2 |
| 重剑轻斩／重斩 | J／K |
| 步枪射击／瞄准／换弹 | J／K／R |
| 开始巨兽试炼／返回世界 | H／B |
| 试炼中闪避／饮药 | Shift／1 |

先接近小怪，观察攻击是否命中以及生命、耐力变化。巨兽试炼中观察抬臂和冲撞，给自己留出闪避的耐力；失败后按照画面提示再次挑战或返回。装备不同，同一个 J/K 按键对应不同动作。Esc 可释放鼠标或进入暂停，继续方式以界面提示为准。

## 让世界发生一次自己的变化

按 [AI 配置指南](AI-SETUP.zh-CN.md) 连接可用模型后，回到当前世界的创作对话，发送一个具体需求，例如：

> 在我附近再种一棵树，优先复用已有素材，保留当前怪物、装备和进度。

也可以在世界入口新建空白 3D 世界，再逐条提出树、花草、小怪、剑、大怪物和 AK47 的需求。每轮先等待检查和应用，再查看效果，随后提出下一条。AI 生成耗时取决于模型服务和需求；不计入上面的 35 分钟游玩安排。已有六步存档可以立即体验完整结果。

公开应用包没有模型凭据；没有可用连接时，前面的探索与战斗仍可试玩，但尚不能体验新的 AI 创作。参赛者须通过评审渠道另行提供专用连接，或评委使用自己的模型服务。
