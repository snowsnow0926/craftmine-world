最中幻想｜评委从这里开始
开放世界，能有我开放吗？一边创造，一边游玩。

【启动】
完整解压应用 ZIP，按下面的入口选择体验。
请运行应用包，不是 GitHub 的源码 ZIP；保留解压后的所有资源文件。
1. 正常试玩／继续本版本：START-PLAYER-PREVIEW.cmd。
   再次启动保留本版本的账号配置、世界与存档。
2. 模拟全新玩家：START-NEW-PLAYER.cmd。
   每次创建全新的资料，不带入旧账号、密钥、世界或设置，也不会删除旧资料。
   资料保存在 %LOCALAPPDATA%\CraftmineWorld-NewPlayers\player-唯一编号。
   同时在 NEW-PLAYER-SESSIONS 中生成 CONTINUE-唯一编号.cmd。
   同编号 PLAYER 文本记录资料路径与创建时间，方便区分不同试玩玩家。
   下次继续这位玩家，请用这个对应的 CONTINUE 入口；不要再次点新玩家入口。
3. 继续 preview.27 的旧世界：CONTINUE-PREVIEW27.cmd。
   使用原来的 %LOCALAPPDATA%\CraftmineWorld-FirstCreationPreview27。
新玩家没有旧世界是正常的，可创建空白世界，或先导入下面的示例。

【先看核心玩法：约 3 分钟，不含首次加载】
1. 世界入口 → 我的模板 → 导入世界模板 ZIP。
2. 选择 examples\deepseek-six-step-playtested.zip；填入新世界名称，
   点击“创建独立世界”，等待准备并进入，切换“游玩”。
3. WASD 移动、方向键转视角；按 3 切换重剑，J 轻斩、K 重斩。
   按 2 切换 AK47，J 射击、K 瞄准、R 换弹。
   按 H 开始巨兽试炼，观察攻击并尝试还击；B 返回世界。
4. 回到创作界面，使用“保存”，看到已保存后正常退出。

这是 AI 六轮创作留下的真实存档：树、花草、小怪、重剑、巨兽与 AK47
均已存在；已击败一只小怪，步枪已换满弹。无需重新调用 AI。
以上按键仅对应这份战斗模板；其他世界以画面提示为准。

【完整体验】
打开 docs\REVIEWER-30MIN.zh-CN.md：伙伴、雨城、驾驶、战斗与存档，
安排约 35 分钟实际游玩；生成和加载等待不计入游玩时间。
七份世界模板均在 examples 中，导入后创建的是独立副本。

【亲自“言出法随”】
已有模板可不连接 AI 直接游玩；文字或语音驱动新创作需要联网并连接模型。
本包不含 API 密钥或登录账号。请使用参赛者通过评审渠道单独提供的
专用连接信息，或自己的可用模型账号。配置见 docs\AI-SETUP.zh-CN.md。
进入一个世界后发送：“在我附近再种一棵树，优先复用已有素材，保留现有内容。”
等待制作与检查；看到已应用后再进入世界查看。若界面提供“应用到世界”，
完成该步骤再查看，不能仅凭对话中的“完成”判断内容已经进入世界。

【遇到问题】
Esc 释放鼠标后回到创作界面；先看当前任务与检查提示。
任务明确失败时使用页面提供的继续或重试，不要反复刷新、重复发送需求。
AI 服务不可用时仍可游玩上述模板。退出前正常保存；不要同时打开两个
应用实例操作同一份资料。需要反馈时，记录世界名称、操作步骤与错误截图。
