# 最中幻想：连接 AI 并开始创作

包内世界可不连接 AI 直接游玩。让 AI 新增或修改内容需要网络与可用的模型服务。**公开 ZIP 不含 API 密钥、开发者账号或已登录资料。** 请使用参赛者通过评审渠道单独提供的专用连接信息，或自己的模型账号。

## 推荐入口：提供商后端

1. 打开左下角“设置”，进入“模型”，在“AI 服务”区域点击“添加服务”。
2. 官方服务可在“服务”中选择对应厂商，并填写“API 密钥”。评审专用地址或第三方地址选择自定义服务，按提供的信息填写名称、“接口地址”、“API 密钥”和“接口格式”。地址与密钥必须属于同一服务。
3. 等待模型列表，勾选实际可用的模型。列表未列出时，使用“添加自定义模型”，填写服务方给出的**模型 ID**，不要仅填宣传名称。
4. 点击“测试连接”，按结果处理，再“保存”。测试通过表示当前连接可用，实际创作仍取决于模型权限、额度与服务状态。
5. 在“设置” → “AI”的“世界创作后端”保持“提供商后端（默认）”。回到世界的创作对话，确认输入框下方选择的是刚配置的服务、模型与所需思考等级，使用 Agent／智能体模式。需要自动检查并更新世界时，可选择界面中的“全自动”。

本项目此前六步造物实测使用 DeepSeek 官方接口 `https://api.deepseek.com`、OpenAI Chat Completions 格式，以及服务实际返回的 `deepseek-flash` 模型。测试配置为上下文窗口 **1000000**、最大输出 **384000**、思考等级“最高”。这些是该次实测配置；使用其他服务或账号时，按其实际模型能力填写，不能靠扩大本地数字获得服务端没有开放的能力。

若需要修改模型限制，在服务的模型设置中查看“上下文窗口”“最大输出”“思考等级”。最大输出是单次请求的输出上限，也会影响应用为回复预留的空间；它不是已经用掉的 Token。多轮总 Token 累计也不是当前上下文占用。不要只为压低界面数字而删掉世界的必要创作信息。

## 发出第一个愿望

先进入一个已有世界或新建空白 3D 世界，再打开该世界的创作对话。建议第一次使用文字输入：

> 在我附近再种一棵树，优先复用已有素材，保留现有内容和游玩进度。

等待模型制作、检查和应用。若有澄清，请按自己的真实需求回答；若界面显示“应用到世界”，完成应用后再进入世界查看。全自动模式下应确认界面已显示应用结果。对话中的“完成”并不单独证明场景已更新。

满意后保存，再提出下一条需求。语音输入还需允许麦克风并完成当前语音服务设置；文字可直接验证同一创作流程，不必先配置语音。

## 可选入口：已有兼容 Codex CLI 的电脑

在“设置” → “AI” → “世界创作后端”选择“本机 Codex CLI（实验）”，点击“检测 CLI”或选择已安装的程序，再“验证连接”。需要时按界面“开始 ChatGPT 登录”，验证成功后“保存世界后端”。

此预览适配器要求 `codex-cli 0.154.0-alpha.6.2` 和账号可用的 `gpt-6-astra / xhigh`。CLI 需单独安装，应用没有内置，也不会自动安装；普通安装器可能提供不兼容版本。没有兼容安装时，先使用上面的提供商后端。此入口用于 Godot 世界的 Agent 对话，其他对话与 Plan 仍使用提供商后端。

## 连不上时

- 提示认证失败：核对密钥、接口地址、账号权限及余额，联系提供连接信息的人。
- 模型不存在或接口格式错误：核对实际模型 ID 与服务使用的协议，修改后重新测试连接。
- 服务长时间没有回应：查看任务状态，可正常停止；服务恢复后使用页面提供的继续或重试。请勿反复发送相同创作需求。
- 世界更新失败：保留当前世界，查看检查记录和错误提示；保存可用进度，记录复现步骤与截图。

评审专用连接应由参赛者在提交渠道单独提供，并保证评审期间可用。应用包、公开仓库和宣传截图中都不需要放入个人密钥。
