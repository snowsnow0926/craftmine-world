# 连续造物与 preview.11 成品开发计划

日期：2026-09-11。源码基线：`fa9f7247`。上批 NB0–NB7 已完成工程验收，最近安装包仍为 `0.14.4-preview.10`。本计划是下一批独立目标，保留此前报告、模型预算及原始失败。

## 为什么优先做这一批

现有功能已经能创造、直接编辑、检查、采用与保存。下一步的主要价值是减少玩家找回对象和重复等待的成本，并把现有能力真正交付到可测试的 Windows 成品中。

| 已核实的缺口 | 本批选择 | 价值 |
| --- | --- | --- |
| 目标采集只认当前射线，采用后的产物没有明确回选入口 | 从正式采用的回执列出最近结果，玩家显式选回具体对象 | 转身、同名对象、连续对话后仍能修改正确对象 |
| 底层已经支持放置、复制，直接编辑界面只开放尺寸、颜色、删除、撤销 | 五种现有对象的直接放置及有限复制 | 常见造物无需模型调用，操作结果可撤销、可重开 |
| 宿主只识别少量固定中文改色句，结构化操作却已支持颜色与尺寸组合 | 有界中文颜色、明确尺寸和单对象组合愿望 | 常见表达获得完整的实际结果验收，未知附加要求不会被吞掉 |
| 检查完成先于采用回调，模型回合结束可能与采用交接竞争 | 先做确定性复现，再闭合检查、采用和等待状态 | “检查通过”不会被误当作“世界已经改变”，取消和过期保护仍有效 |
| 新功能仍只存在于源码和开发构建，旧随包指南已落后 | 同一源码打包 preview.11，运行包内客户端验收并提供中文试玩说明 | 用户能直接测试本轮和上批新增功能 |

最后 HOLDOUT01 在前三次请求中已经修改源码、启动检查，并读到检查通过及候选 ID；随后预算耗尽且正式颜色未改变。现有记录不足以断言一定发生采用竞争，也不能称为颜色引擎损坏。本批先以受控时序验证，不改写旧失败。

## 并行开发与依赖

仅使用 Codex 子 agent。CN1、CN2、CN3 在三个独立工作树并行；总控负责 CN4、接口协调和集成，随后复用完成任务的子 agent 做独立审查、包内验收。CN2 的结构化意图与 CN3 的文字解析共享宿主要求契约，不各自生成不同标准。CN1 的选择来自正式回执和当前真实采样，不能把显式选择伪装成射线。

接口优先复用 `creation-operation`、`CreationCapture`、正式操作日志、耐久任务和现有 Godot 执行/应用机制。没有明确收益的引擎、存档、包格式重写不纳入本批。

## 验收故事

1. 进入空白世界，通过界面直接在此处放树；没有模型请求。
2. 转身或指向另一棵同名树，从最近结果选回原树；改颜色或用明确的组合愿望调整它。
3. 复制两棵，分别选中其中一棵并修改；原树和另一副本不变。
4. 撤销一次已完成操作，保存退出并重开；世界内容、位置、背包及已有一次性领奖历史一致。
5. 复制整个世界并继续创造；副本使用独立会话，原世界和原会话历史不变。
6. 在最终包内 EXE 重跑主要流程，记录包身份及真实 core/Godot 证据，再提供中文试玩清单。

负例必须包括：最近结果已删除/不可见/来自另一世界；多结果不自动猜选；占用和玩家重叠；连续提交/丢回复/旧 capture；错误颜色或尺寸/附加未知要求；检查通过但尚未采用；采用过程中取消、切换世界、源码过期和失败；重开后未确认结果不自动重放。

## 真实模型试验边界

本批最多一个正式开发验证轮次，最多四个案例，每例独立预留 10 次请求，总上限 40 次，每例最多 10 分钟与 2 次模型修复。已授权的本地提供商配置只用于隔离测试，不改个人设置、不购买额度；模型实际可用性核对后记录其准确身份。费用无账单则保持未知。

模型调用前冻结案例、初始世界/实体、源码、检查器、模型和预算清单。优先覆盖带颜色的放置、同一对象尺寸与颜色组合、最近结果上的继续修改，以及原改色表达在完整独立预算内的执行。每例从独立初始状态开始，夹具仅准备输入，不替模型写入答案；模型原话、工具、用量、检查与采用分别留证。若采用竞争的确定性修复仍未完成，先完成修复，不用付费调用代替调试。

本轮属于开发样本，不声称独立未见保留集或普通玩家总体成功率。达到额度后不追加轮次、不复用旧预算获取新额度；任何补验只能验证已生成产物，单列并不覆盖原始结果。失败不会阻止完成产品修复和如实交付，但正确性阻断缺陷必须修复后再生成成品。

## 验证纪律与交付范围

自动验证使用独立 headless/offscreen、不可聚焦进程和测试档案，初始化禁用 Pointer Lock，仅使用页面脚本、HTTP、IPC 或逻辑断言。不发送真实鼠标键盘、不激活测试窗口、不操作用户浏览器，不运行 `tests/browser.mjs` 或 `tests/modules-browser.mjs`。

优先使用现有 `desktop/build-client.ps1 -Installer`、资源预检、包封存与验证工具。运行资源必须按本轮提交重新 stage，不能改旧清单的提交号冒充新资源。包内验收通过实际 EXE/ASAR/资源执行；安装器解包不等同于干净系统安装。

真实麦克风、真实玩家舒适度及干净 Windows 首装/升级/卸载，只有实际环境可用且真实执行才算通过；否则准确列为待外部验收，不在个人安装上代测。最终成品放入独立 `D:/Craftmine-World-preview.11`。本批不包含远端 push、自动安装、多人/社区、拖拽编辑器、全面热更新或自动思考档位路由。

完成定义：CN0–CN7 的必要实现、可用环境验收、本地合并与清理完成；中文报告、真实失败、成品及校验清单可复核，用户可以开始实际试玩。随后关闭本批 Goal。
