# 沉浸改造审核修复与 Windows 重新交付

本轮修复审核发现的三个问题：原安装包缺少主世界插件和运行资源；
Godot 草稿预览的操作被全尺寸视图遮挡；完整工作台浮层不能查看文件与评审。

原 120 MB 安装包不作为可测试成品。重新交付必须从干净提交运行
`desktop/build-client.ps1 -Installer`，重建主插件、Rust 服务、执行器、
桌面界面、源码包和许可清单，准备固定 Godot 与 MinGit。

新增 electron-builder 的 Windows 打包前检查。缺失或旧提交的构建清单、
运行资源、插件与桌面输出均拒绝打包；正式交付仍需完成安装器解包、
内容哈希核对和包预检，不能以生成 EXE 代替完整性检查。

验证使用独立测试目录、headless 页面与受保护原生夹具，不操作真实鼠标
键盘，不激活窗口，不请求 Pointer Lock，不读取或迁移玩家存档。
