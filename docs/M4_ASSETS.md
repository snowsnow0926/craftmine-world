# M4 素材进入玩法

更新：2026-09-08。M4.1 已实现，M4 整体验收尚未完成。个人 8787 服务仍是 Alpha 0.7；当前素材开发没有写入个人世界或处理其候选。

## 已完成：素材库与独立预览（M4.1）

在“素材”工作区导入本地 PNG、JPEG 或静态 GLB。文件先经过大小、结构和引用检查，再由独立 headless 浏览器实际解码、上传纹理并绘制。只有检查成功后才加入库。素材拥有稳定 ID、不可变版本和内容哈希；导入新版保留旧文件，界面可以选择历史版本、预览和单独导出素材包。

素材包 `craftmine.asset/1` 保存名称、原始数据、格式、尺寸或模型边界、身份和版本。项目索引存储在 `project.json` 的 `assets` 中，原始版本保存在 `assets/<id>/<version>.json`。读取时重新验证内容与索引；同版本内容冲突不能覆盖原文件。检查结果带内容哈希单独保存。导入失败不会改变当前世界、进度或候选。

预览运行于独立的不透明 iframe。它不能访问宿主 DOM、文件系统、网络、Worker 或 Pointer Lock，只接收限定来源和随机握手标识的素材消息。关闭、快速重开和超时会清理旧预览。所有自动验收只使用独立测试项目和后台浏览器，不发送真实键鼠输入。

## 支持范围与容量

- 单文件最多 8 MiB；PNG/JPEG 单边最多 2,048 像素。模型最多 50,000 个三角形、128 次网格绘制、512 个节点、8 张内嵌图片；累计纹理像素和访问器解码也有限额，先检查再分配。
- GLB 读取实际索引和顶点、交错与稀疏访问器、三角带/扇、节点层级和 TRS/矩阵变换，处理负缩放、法线、UV、顶点颜色与内嵌 PNG/JPEG。
- 支持基础颜色贴图、不透明/裁切/半透明、双面与无光照材质。当前光照是简化模型，并非完整 PBR；高级材质回退会给出提示。
- 动画、蒙皮、变形目标、外部资源 URI、压缩网格及不支持的必需扩展明确拒绝，不伪装成成功导入。需先从建模工具导出静态、资源内嵌的 GLB。
- 库最多 256 项，每项最多 64 个版本，原始文件累计最多 512 MiB。素材单独导出/导入已支持；世界与创作模块携带素材的整体迁移仍属 M4.3。

## 下一切片：世界绑定与保留行为（M4.2）

为对象增加固定素材版本引用和外观变换，实际接入游戏渲染。现有几何继续表达碰撞与交互范围；外观替换不改写对象 ID、玩法源码或状态版本。先形成可预览的候选，应用时继续使用原世界最新进度。验证图片与标准模型在世界中的显示、源码驱动位移和隐藏、旧外观回退、缺失素材拒绝及失败后原世界保持可玩。

资产内容进入受校验的运行构建，不把二进制 Base64 塞进模型提示词。模型只读取真实库中可用的素材描述和固定版本引用。任何引用不存在、哈希不匹配或超出世界资源预算的产物都不能成为可应用候选。

## 最后切片：跨项目复用与真实模型（M4.3）

完整存档和带源码的创作模块应携带所需素材版本，导入第二个项目时重新验证。验证同版本冲突、旧版固定、新版替换与回退，并让真实模型完成一次素材绑定/替换，证明既有互动仍工作。完成这些证据后再集中交付下一 Alpha，不能把素材库预览作为整个 M4 完成的依据。
