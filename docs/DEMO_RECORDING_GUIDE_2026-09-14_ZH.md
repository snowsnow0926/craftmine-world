# Demo 实测与宣传片录制指南

本轮沿用 PI Desktop 的世界、创作对话和素材库界面。请使用本次交付的新 Windows 包；实际版本和目录以随包交付说明为准。

## 开始前

完整解压，运行 `START-PLAYER-PREVIEW.cmd`。入口页进入“我的模板”，导入随包 ZIP，再创建自己的世界。提前完成首次导入和加载，下面的时间从世界出现后计算。

| 素材 | 随包文件／模板 |
| --- | --- |
| 庭院组合 | `examples/matched-courtyard.zip` |
| 伙伴与雨天 | `examples/companion-and-rain.zip` |
| 博美与修改后的树 | `examples/pomeranian-and-edited-tree.zip` |
| 轻雨城市、博美与歼二十 | `examples/city-flight-and-companion.zip` |
| 帐篷里的暗影游侠 | 随包提供的暗影游侠世界模板 |

这些模板创建独立副本，并带入作者保存的进度。城市模板的三个通航物品已收齐、飞机已解锁。游玩这些内容不需要 AI 账号；发送新的创作需求才需要配置自己的账号。

## 2–3 分钟实测

建议先用“博美与修改后的树”跑一遍，再在其他世界重复关键动作；首次加载和世界切换耗时单独记录。

1. **前 40 秒：**进入“游玩”，WASD 走动、绕树观察，确认画面和操作连续。走近博美，按该世界屏幕提示尝试互动与跟随；不同模板的伙伴按键可能不同。
2. **40–80 秒：**F2 打开创作对话，Shift+F2 展开，Esc 收起。输入一条修改需求，检查输入和界面切换是否顺畅。需要真实创作时再发送，并等待实际检查、应用和画面变化；录屏时长不代表制作时长。
3. **80–150 秒：**使用普通“保存”，看到完成提示后关闭并重开同一世界，检查位置、对象和互动进度。把实际保存、重开耗时记下来。

另做两个短检查：在暗影游侠模板中走近帐篷里的角色，按 E 查看对白，向角色走几步确认阻挡；在城市中按 M 查看地图，靠近小麦按 E 抚摸、H 切换跟随。飞机停稳时按 E 登机，C 切换视角；完整驾驶按随包城市操作指南进行。

## 60–90 秒宣传片镜头

| 时段 | 建议画面 |
| --- | --- |
| 0–10 秒 | PI Desktop 入口、“我的模板”、创建副本，切到庭院全景。 |
| 10–25 秒 | 博美与树：绕树近景、伙伴互动，展示对象确实在世界里。 |
| 25–38 秒 | 伙伴与雨天：雨景和同行镜头。 |
| 38–58 秒 | 轻雨城市：街区、地图、博美，再接飞机座舱或已录好的起飞片段。 |
| 58–73 秒 | 暗影游侠：帐篷内角色近景、E 对白，切回完整场景。 |
| 73–90 秒 | 现有创作对话与已完成作品，普通保存后重开，收在世界画面。 |

可剪成 60 秒版本。生成过程用已有真实记录；跳过等待或加速时标注“过程节选／加速”，避免让观众误以为复杂世界瞬间完成。录制前收起账号设置和密钥。

本片使用上面的已认可示例和已验证游侠模板。新增双狗城市的导航仍在排查，不作为导航成功镜头；空白世界完整创作流程尚未完成验收。

遇到卡顿、黑屏或“完成但没出现”，记录世界名称、应用版本、原始指令和出错前后的画面，可在“朋友试玩与反馈”导出记录。
