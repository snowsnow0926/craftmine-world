# 最中幻想 · craftmine world · 3D 方块创作原型

版本：0.2 · 林间起点

项目正式名称于 2026-09-08 确定：英文 **craftmine world**，中文 **最中幻想**。交接材料中的「世界工坊 / World Workshop」是旧暂名。源码目录暂保留 `world-workshop-3d`，存储键及存档、卡带格式标识沿用 0.2 原型约定，以兼容既有数据；新导出文件使用 `craftmine-world-` 前缀。

这是一个可进入、可走动、可修改的第一人称 3D 方块世界，同时演示游戏开发 Harness 的三个入口：开发对话、运行试玩、素材绑定。它不是视频或静态设计稿。

**范围说明：Agent 目前是本地中文预设指令适配器，不是真实模型，没有自主修改代码。** 世界、相机、碰撞、方块搭建、采集、配置应用、导出与导入都由本地代码实际执行。素材工作区提供三种程序化树木外观，不包含真实 AI 生图或 3D 模型生成服务。

## 打开

直接用桌面浏览器打开本目录的 `index.html`。无需安装依赖、填写 API Key 或联网加载运行库。HTML 中已包含所有样式、脚本和程序化素材。

聊天中的文件预览未必允许运行脚本；请保存 HTML 后在浏览器中打开。优先在电脑上体验鼠标和键盘；手机布局和触屏控制也已提供，但未在真实 Android / iOS 设备上验证。

需要固定的本地网站地址时，可在本文件所在目录运行：

```sh
python -m http.server 8000
```

再打开 `http://localhost:8000`。直接打开文件与使用本地网站是不同的存储环境；切换前先导出完整存档。

## 先体验这条流程

点击“进入世界”，走动或环顾。初始出生点前方有一棵树，将准星对准它后按 **T**，在右侧输入：

> 让树木可以被砍，每次掉落3份木材

发送后，预设执行器会准备候选配置，但不会立即改变正在运行的世界。你仍可回到场景继续游玩。点击“应用并继续玩”后，再瞄准这棵树按 **E**：树木消失，背包增加木材。

然后尝试：

> 在河上建一座桥

> 把树木换成樱花粉色

> 把世界变成夜晚

木桥在演示地图预定的过河位置生成，并非任意位置的结构生成。也可以通过“素材”工作区选择树冠外观并绑定。更新时保留应用瞬间的位置、背包、采集记录和手动方块；若更新后的几何体与玩家重叠，会寻找安全位置。

最后用方块搭建一点内容，点击“打包卡带”。**世界卡带会包含手动搭建和已采集的树木，不只是界面上的配置。**

## 操作

| 操作 | 键位 |
| --- | --- |
| 前后左右移动 | W A S D / 方向键 |
| 环顾 | 鼠标；鼠标未锁定时按住场景拖动 |
| 跳跃 | Space |
| 冲刺 | Shift |
| 破坏单个方块 | 左键 / R |
| 放置方块 | 右键 / Q |
| 选择六种创造方块 | 1–6 / 鼠标滚轮 / 点击快捷栏 |
| 采集整棵树（需先启用采集规则） | E |
| 步行 / 创造飞行切换 | F |
| 飞行上升 / 下降 | Space / Shift |
| 撤销最近的手动方块操作 | Z，最多最近 40 步 |
| 携带准星对象上下文打开 Agent | T |
| 释放鼠标或退出弹窗 | Esc |

鼠标锁定需要先点击“进入世界”。若浏览器不允许锁定，仍可按住场景拖动环顾，用 WASD 移动、R 破坏、Q 放置。

触屏：左侧摇杆移动，拖动场景环顾，右侧按钮跳跃、破坏、放置和采集；底部按钮打开 Agent。创造方块为无限材料，与采集获得的木材计数分开。

## 三个工作区

**开发**：查看同一项目的需求、预设示例与配置历史。对话中的“讨论”只记录和回应，不修改世界；“执行修改”仅处理已实现的预设字段。

**游玩**：实际第一人称 3D 场景，带地形、河流、树林、小屋、准星与小地图。有重力、跳跃、碰撞、方块放置与破坏、创造飞行。按 T 可把正在瞄准的树木实体作为上下文传给对话。

**素材**：青绿、樱粉、金秋三种树木预设外观，提供绑定范围与玩法保留提示。外观变化不会自动清除已启用的采集玩法。

三个工作区共用项目、任务和候选版本。对话框只模拟已支持的中文需求；复合句中未识别的额外需求不会执行，界面会明确提示这个边界。

## 存档、回退与卡带的区别

- **本地自动保存**：写入此浏览器的存储。受浏览器权限、隐私模式、存储空间与打开地址影响；不是云存档。出现存储不可用提示时，使用“导出存档”。重要进度应主动备份。
- **配置版本回退**：保留最近 10 个配置版本，只退回规则与外观，不倒退已经获得的背包、手动搭建或采集进度。不能用它恢复手动挖掉的方块；最近的手动操作用 Z 撤销，完整恢复使用存档或归档。
- **完整存档**：包含配置、位置、朝向、背包、手动方块和采集记录。底部“导出存档”导出；右上角帮助窗口可导入。导入前把当前世界归档。
- **世界归档**：切换新世界卡带或导入存档时保留旧世界，最近 3 个可在版本窗口恢复；恢复时也归档切换前的世界。
- **世界卡带**：包含规则、外观、手动方块与已移除树木，但不携带玩家个人位置或背包。安装会进入一个新的起点，并先归档当前世界。
- **玩法模组 / 素材包**：只携带该类型允许的配置，经过差异预览后应用到当前世界。

卡带格式：`world-workshop-cartridge/0.2`；运行约定：`voxel-webgl@0.2`。仅兼容这版演示运行器。上一版 2D 的卡带不会自动兼容；这不是通用游戏插件标准。导入只接受白名单 JSON，不执行任意脚本，不授予文件、网络或开发环境权限。

本地卡带库最多保留最近 15 张卡带。导入文件最大 2 MB；手动方块差量最多 12,000 格。每张卡带的“使用说明”是作者填写的元信息，不是授权审核。

## 已实现与尚未实现

已实现：96 × 96、最高 40 格的有限世界；36 个 16 × 16 水平区块；第一人称相机与角色物理；可编辑方块；84 个稳定树木实体；实体级采集规则；可应用和回退的候选配置；实际世界内容卡带与完整存档。

尚未实现：真实 Agent / 后端任务执行、任意需求编程、AI 图片或模型生成、通用模型导入、多人联机与共创、公开社区市场、无限地形、怪物与完整生存系统、跨引擎卡带、任意脚本模组。不要把本演示当作可运行不可信插件的安全沙箱。

体素世界是 Harness 的第一个运行示例，不应把未来平台限定成只能制作方块游戏。

## 渲染与兼容

默认尝试内置 WebGL 渲染器。没有可用 WebGL 时，自动使用同一世界数据与相机的 Canvas 透视 3D 兼容渲染路径，而不是退回等距 2D 游戏。兼容渲染的纹理、遮挡精度和性能与 WebGL 不完全相同。

原型此前的交付环境无法创建浏览器 WebGL，随附交互截图使用兼容 3D 路径。历史报告记录三个 WebGL 着色器程序通过原生 EGL / GLSL ES 编译和链接检查，但**这不代表已验证浏览器中完整 WebGL 绘制路径的实际画面**。不同设备的性能仍需实测。

## 源码与构建

```text
src/index.template.html   工作台结构
src/styles.css           桌面与触屏界面
src/voxel-runtime.js     地形、几何、渲染、输入、碰撞、方块与运行状态
src/workshop.js          对话预设、候选配置、素材绑定、版本、卡带与存档
build.py                合成为离线单文件
index.html              可直接打开的构建结果
```

修改 `src` 后运行：

```sh
python build.py
```

不需要 npm 或远程依赖。全部视觉资源由代码绘制，没有打包 Minecraft 官方素材、外部图片或字体文件。

## 验证记录

`test-report.json` 是原型交付时附带的 42 项自动化检查历史记录；`shader-test-report.json` 记录当时的原生着色器验证。这些报告不是更名后在当前 Windows 环境重新运行的结果。历史测试使用 Chromium、Playwright，以及仅用于测试的内存存储替身。受当时环境策略限制，页面通过 `set_content` 加载；没有更改浏览器策略或访问外部网络。

已覆盖移动方向、对角移动、跳跃与碰撞、放置与撤销、采集规则、候选隔离、应用时保留最新进度、外观替换、实体作用域、JSON 拒绝规则、实际内容导出、世界归档恢复、序列化往返、移动端布局与触控。

未验证：真实浏览器持久存储跨重启、原生鼠标锁定权限、真实 Android / iOS 设备、正常下载权限下的文件保存，以及浏览器 WebGL 实际绘制。测试中的导出通过 Blob 内容捕获校验，而不是把环境禁止的原生下载当作成功。

安装好 Python Playwright 与 Chromium 后，可执行：

```sh
python tests/test_workshop.py
python tests/test_additional.py persistence
python tests/test_additional.py mobile
```

测试脚本默认使用 `/usr/bin/chromium`；其他平台需调整该路径。`test_shaders.py` 额外需要本机 EGL / GLES 库。测试报告随交付提供，不要求使用者自行配置测试环境才能试玩。
