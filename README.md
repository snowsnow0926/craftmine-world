# 最中幻想 · craftmine world

正式英文名：**craftmine world**。正式中文名：**最中幻想**。

名称于 2026-09-08 确定，替代交接材料中的旧暂名「世界工坊 / World Workshop」。后续界面、文档与项目介绍以正式名称为准。

## 产品方向

这是服务于游戏创作的 Agent Harness。创作者可以在游戏外描述需求，也可以进入自己的游戏，在游玩现场向 Agent 提出修改；Agent 完成开发并产出候选版本后，创作者主动应用、重新载入并继续体验。

第一版目标已明确为：从一个能走动的空白 3D 世界开始，接入 LLM 后输入“我想要有树”，系统实际开发并把树加入世界，然后能够指向这棵树继续修改、保存并重新进入。详见 [产品想法](docs/PRODUCT_VISION.md)。

- 开发工作区：讨论、执行任务、预览与版本管理。
- 游玩／创造工作区：运行真实游戏，携带玩家位置、所指对象及版本上下文提出需求。
- 素材工作区：生成或导入、预览、绑定对象、在场景中应用与撤回。

三个工作区共享同一项目、任务与资产。3D 方块世界是首个示例运行器；多人共创、卡带与模组复用、社区生态属于后续方向。

## 当前源码

主线源码在 [world-workshop-3d/](world-workshop-3d/)，当前为 0.2「林间起点」原型。目录保留旧名；根目录的 `world-workshop-3d.zip` 是原始交接包。

原型已有第一人称方块世界、搭建、采集、三个工作区、候选配置应用与回退、存档与受限 JSON 卡带。Agent 目前只解析本地预设指令；真实模型开发、AI 素材生成、多人和社区尚未接入。

- [运行与操作说明](world-workshop-3d/README.md)
- [结构与实现边界](world-workshop-3d/ARCHITECTURE.md)
- [可直接打开的原型](world-workshop-3d/index.html)
- [产品梳理与开发计划](docs/DEVELOPMENT_PLAN.md)（含已确认范围、阶段验收与第一个开发切片）

在本根目录运行以下命令重新构建；Windows 安装了 Python Launcher 时也可用 `py` 替换 `python`：

```sh
python world-workshop-3d/build.py
python -m http.server 8000 --directory world-workshop-3d
```

然后打开 <http://localhost:8000>。沿用同一浏览器和访问地址可继续使用该地址下的本地数据；切换访问地址前应导出完整存档。

## 接手基线与后续优先级

本轮更名更新界面、文档、内置示例署名及下载文件名，沿用原存储键、存档格式、卡带格式和内容 ID。随附截图与测试报告保留为历史材料，不代表当前环境的重新验收。

后续优先验证当前环境的运行与持久化，再打通真实 Agent 在隔离开发副本中修改项目、验证构建、提交候选、由用户应用的最小闭环。应用时保留最新兼容进度，失败保住旧版本和存档；随后推进一种真实素材绑定与一次兼容项目间复用。
