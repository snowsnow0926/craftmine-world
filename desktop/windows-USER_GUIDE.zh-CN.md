# craftmine world / 最中幻想 Windows 使用说明

这是本机个人创作客户端。世界、草稿、作品与进度保存在本机；联网模型负责协助创作。安装包与独立程序目录需要保留配套资源，不能单独复制一个 EXE。

## 安装、启动和模型

1. 先关闭正在运行的 craftmine world，再运行 `Craftmine-World-Setup-版本.exe`。安装器会先尝试保存本机世界数据副本；数据仍被占用或备份失败时停止安装。安装完成不会自动启动程序。
2. 也可以将 `win-unpacked` 整个文件夹放在自己的目录，运行 `Craftmine World.exe`。普通使用不需要安装 Node、Rust 或 pnpm；这一点仍需在干净 Windows 机器最终验证。
3. 打开模型设置，选择自己的供应商、模型与密钥。客户端不会自动读取另一个 PI-Desktop 安装的账号。模型失效、额度耗尽或断网时保留草稿，并显示实际错误。
4. Windows 新凭据使用当前 Windows 用户的 DPAPI 保护。旧版加密文件会先验证迁移，再原子替换密钥文件。保护不可用时不会静默改用明文。更换 Windows 用户或电脑后应重新配置模型密钥。

## 本版造物世界试玩

0.14.4-preview.11 补齐连续造物操作：可以直接放置已有物件、从“最近结果”选回对象，再调整颜色、尺寸或复制；这些界面操作不调用模型，仍需等检查和采用完成。

建议按下面的顺序试玩：

1. 新建造物世界，对准空地并更新指向，使用“放置物件”放一棵树。
2. 移开视角，从“最近结果”选回这棵树；列表显示具体对象身份，不会按同名猜选。
3. 打开“编辑对象”调整尺寸或颜色，再选择“检查并应用”。也可以输入“把这棵树放大到2倍，并改成蓝色”。
4. 将复制数量设为 2，调整副本间距，选择“复制并检查”；再从最近结果选其中一个副本继续修改。复制使用已采用的外观与参数，脚本机关关系不会自动克隆。
5. 撤销一次操作，保存退出并重开，确认内容和进度；复制整个世界后继续创造，检查原世界未变。

选中最近结果后，视角移动不会更换对象。要在新位置放东西，请选择“使用当前指向”并对准空地。删除或暂时不可见的结果会标为不可用；一次产生多个对象时，需要明确选择其中一个。

可以打字或按住说话，语音转写进入同一个草稿；中文识别器缺失时按提示选择或重检，不会静默改用其他语言。模型生成结果仍需通过检查；“检查完成 · 待采用”“正在采用”“已采用”是不同状态。自动采用以真实回执为准，遇到待确认结果先查询原操作，不重复提交。原四种底座继续保留。

## 打开世界并创作

在“世界”面板新建或打开世界。原网页项目可通过面板导入原项目目录或 `.craftmine`；导入形成新的客户端世界，原目录保留。已有世界在不联网时仍可以打开，生成新内容需要已配置的联网模型。

向助手描述想要的东西，例如“在这里放一棵蓝色的树”。常见颜色与明确尺寸组合可做实际结果检查；模糊、冲突或含未支持附加要求的愿望会保留待核验状态。候选草稿、已检查、已应用是不同阶段，查看失败条件及预览后再采用，不把模型文字里的“完成”当作世界已更新。

客户端已接通作品库、记忆、任务恢复和备份。作品复用显示固定版本和依赖，安装后仍须检查、评审及应用；恢复中断任务需要玩家明确选择。真实模型创作、复用、恢复和三次压缩已有验收记录，前批范围见 `docs/WINDOWS_BATCH_06.md`，本批以交付报告为准，不代表全部 W0–W5 验收完成。

## Godot 世界、复制和独立游戏

新建世界可选造物世界、第一人称、俯视、横版和挖掘沙盒；已有底座保留各自起点及示例。新建后需要等待“复制底座、建立工程、首次构建、确认可加载”完成，错误提示中的“重试”会继续同一个世界。世界默认占主要区域，对话在右侧；布局控制可切换显示方式。

“复制世界”先保存当前游玩进度，再为副本建立独立的源码和运行身份。副本完成构建、检查和应用后才能游玩；关闭程序后两份世界分别保存。未应用草稿仍保留在其分支中，不会代替已应用版本成为副本的正式游戏。

Godot 世界的“作品库”支持导出当前源码中的独立对象为 ZIP，再导入兼容底座。重复安装会生成不同对象身份。每次安装提交后台检查；请等检查结束，再安装下一份。检查通过后仍需预览和应用。矿场目录中的组件说明包含手动安装项，不表示所有目录条目都能一键安装。

同一页的“导出 Windows 游戏”会先保存当前进度，然后导出已应用版本。选择目录后等待明确的完成回执，打开新生成的文件夹，双击 `game.exe`；`game.exe` 和 `game.pck` 必须一起保留。独立游戏可用 F5 或保存按钮保存，关闭窗口前也会保存，再次打开会继续自己的进度。源码、引擎许可及来源清单随导出目录附带。当前导出属于本地预览，素材和模块的待确认权利不会因导出而自动获得授权。

## 任务额度、缓存与中断恢复

世界工作台的“任务”页显示本地累计用量与预留量。新任务默认不限制累计 token；
旧任务可以选择“解除本地累计 token 上限”或设置新额度，然后明确恢复任务。
解除上限会保留原草稿、已用额度和未知请求的预留量。请求次数、压缩次数、时限，
以及模型单次上下文与输出容量仍是不同限制。

当前独立边界为每任务 80 次请求、8 次压缩、首次请求起约 30 分钟的绝对时限。
解除 token 上限不会延长已经到期的任务；过期任务目前仍可能显示通用“继续创作”按钮，
下一次请求会显示时限错误。不要靠重复点击恢复来绕过。

“结束此草稿任务”会保留历史记录，但后续新任务从**已应用世界**开始，
不会自动继承尚未应用的草稿。未应用改动重要时，先在“备份与诊断”导出全部资料并等候
成功回执。备份保留历史，不是自动续期或一键重新挂载历史草稿的方法。

缓存命中率来自模型服务返回的用量。“未缓存输入”与“缓存读取”分别显示；
固定内容预热后可以有较高命中率，新增内容、工具发现或上下文压缩时可能下降。
缓存复用不会免掉真实 token 用量，也不会代替作品库或持久记忆。

待确认操作保存了原操作编号。刷新或重启后先确认原结果；显示完成后使用
“确认已完成”收起回执。作品安装成功但检查提交失败时，使用“重新检查草稿”，
不必重新安装。评审的失败断言会保留，玩家可以选择“带评审提示应用”；
独立机器检查和实际加载仍必须通过。

## 导出与恢复备份

集成后的备份按钮由 Windows 文件选择器选择位置，不要求在聊天里输入文件路径。

- 备份范围是**这个客户端的全部世界、作品与领域记忆**，不是当前世界一项。
- 备份排除凭据存储和 Chromium 缓存，但包含任务需求、记忆和相关证据；其中可能保留你输入的原文。不要把领域备份当作可分享的脱敏诊断。
- 恢复先选择备份并检查内容，再明确确认。恢复会替换客户端的领域资料；当前任务仍在工作、原世界已改变、备份被替换或损坏时拒绝提交。
- 备份选择授权十分钟有效。过期后重新选择文件；不要把授权编号转发给模型。
- 恢复不会自动重新运行旧模型任务。跨机器导入的记忆/作品信任状态由 Rust 重新核对。

## 升级与失败处理

升级前先在客户端导出领域备份，关闭程序，再安装新版本。安装器还会在本机档案的 `upgrade-backups` 下创建只读数据副本并记录哈希；这一离线快照只用于本机升级回滚准备，不是可携带 JSON 备份，也不会自动覆盖当前数据。清单中的 `credentialStoreIncluded:false` 表示没有复制凭据存储目录；快照保留 PI 会话文本，其中可能包含用户自己粘贴的敏感内容，因此不能作为可分享的诊断文件。

如果升级前备份失败，关闭程序后重试，保留错误提示；不要删除世界目录来绕过。新版本启动失败时，保留升级副本和原程序目录，先核对发行材料中的来源提交与兼容范围。不要让不认识新数据格式或 DPAPI 格式的旧程序写入当前档案。可正常启动的兼容客户端可用“恢复备份”恢复先前导出的领域文件。

卸载默认保留 `%LOCALAPPDATA%/CraftmineWorld`。手动设置 `CRAFTMINE_DATA_DIR` 时使用该明确目录；它必须是绝对路径。安装与升级脚本不读取 PI-Desktop 的个人档案。

## 导出诊断

诊断只包含版本/来源哈希、系统类型、任务状态与计数、凭据保护状态，以及已采集的启动/帧/模型作业耗时和主进程内存。没有采样的指标显示无样本，不当作零耗时。默认不导出密钥、聊天、个人路径、世界源码或原始日志。

启动采样表示进程启动到首个桌面文档载入，并不包含后续世界载入。帧采样记录可见桌面的动画回调间隔，窗口隐藏时不补零；它不等于显卡绘制耗时。模型作业按完整 Agent 任务和单次评审请求分开列出，前者包含工具和网络等待。诊断保留最近的有限样本，不能据此宣布性能基准通过或推断其他电脑的速度。

当前构建是未签名的本地预览；不会自动更新到 PI-Desktop 上游版本。目前没有可用的隔离 Windows 测试机，Windows 首装、覆盖升级、卸载与没有开发工具的干净系统测试尚未完成。已准备隔离 CI 验证入口，尚未实际运行；不能把“安装包已生成”当作这些项目全部通过。
