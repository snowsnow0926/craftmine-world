# Rights statement: 3D first-person base (shipped base directory)

Scope: every file below `desktop/godot/bases/first-person`, as pinned by
`desktop/delivery/base-assets/bases-first-person.json`.

Status: **project-authored, formal licence application pending.**
This document is a rights statement, not a licence text. It does not grant
anything and it does not replace the licences named below.

## 1 What this base contains

- Authored GDScript, scenes, Godot resources, project configuration and
  documentation written for this repository.
- Geometry generated by `tools/generate_meshes.mjs` from vertex data authored in
  that script, materials and the `icon.svg` icon.
- Godot-generated `.uid` sidecars and the Godot import cache, which is
  gitignored and never shipped.

No third-party model, texture, HDRI, font, sound or shader is included,
downloaded, converted or referenced. See
`desktop/godot/bases/first-person/assets/provenance/ASSET_PROVENANCE.md`.

## 2 Rights holder and evidence

- Rights holder for the authored content: **Craftmine World project**.
- Evidence: the file history of this repository. The files were introduced by
  the base authoring tasks and have not been replaced by external downloads.
- The geometry, materials and icon carry a formal MIT grant in
  `licenses/ORIGINAL_ASSETS_LICENSE.txt`, which is why those entries in the
  provenance manifest use `license: "MIT"` with that notice attached.

## 3 Target licence and what is still open

Per `docs/LICENSING_STRATEGY.md` the confirmed targets are MIT for the code a
player-exported game needs, and AGPL-3.0-only or a commercial licence for the
creation core. `desktop/delivery/base-assets/bases-first-person.json` records
`targetLicense` per entry and `rightsStatus: pending-formal-application`.

Still open:

- per-file authorship confirmation before the MIT grant is applied to the export
  runtime files (tracked in `desktop/delivery/licensing/inventory.json`);
- the formal licence text, copyright holder string and commercial scope review by
  counsel;
- the boundary between creation-core files and export-runtime files, which is
  currently derived from directory and distribution role, not from a legal review.

- PI-Desktop and its modifications (LGPL-3.0-or-later).
