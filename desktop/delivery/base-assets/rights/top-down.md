# Rights statement: 2D top-down base (shipped base directory)

Scope: every file below `desktop/godot/bases/top-down`, as pinned by
`desktop/delivery/base-assets/bases-top-down.json`.

Status: **project-authored / project-generated, formal licence application pending.**
This document is a rights statement, not a licence text. It does not grant
anything and it does not replace the licences named below.

## 1 What this base contains

- Authored GDScript, scenes, JSON world data, templates and documentation written
  for this repository.
- Pixel art generated by `tools/make-assets.mjs`: pure programmatic drawing plus a
  fixed-seed pseudo-random dither, written as PNG through a minimal encoder that
  uses only Node's built-in `zlib`. See
  `desktop/godot/bases/top-down/ASSET_SOURCES.md` and
  `core/assets/ASSET_MANIFEST.json`.
- Godot-generated `.uid` sidecars and the gitignored import cache.

No third-party tileset, sprite, font, audio or Godot plugin is included. Nothing
was copied from another game's data files.

## 2 Rights holder and evidence

- Rights holder for the authored and generated content: **Craftmine World project**.
- Evidence: the file history of this repository plus the deterministic generator
  `tools/make-assets.mjs`; regenerating with the same seed reproduces the same
  bytes, which is why the generated PNGs are declared with
  `origin: "generated"` and the project as rights holder.

## 3 Target licence and what is still open

Per `docs/LICENSING_STRATEGY.md` the confirmed targets are MIT for the code a
player-exported game needs, and AGPL-3.0-only or a commercial licence for the
creation core. `desktop/delivery/base-assets/bases-top-down.json` records
`targetLicense` per entry and `rightsStatus: pending-formal-application`.

Still open:

- per-file authorship confirmation before the MIT grant is applied to the export
  runtime files and generated art (tracked in
  `desktop/delivery/licensing/inventory.json`);
- a decision on whether generated pixel art ships under MIT or under the
  AGPL/commercial path, since it is content rather than runtime code;
- the formal licence text, copyright holder string and commercial scope review by
  counsel.
