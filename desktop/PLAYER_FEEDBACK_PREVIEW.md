# 0.14.4-preview.1 测试版说明

这是基于同一源码重新构建的本地反馈修复候选，最终可用包路径、哈希与实际验收结果以本轮交付清单为准。本文件不表示已经完成打包或玩家复测。

- 修复新 Godot 世界在隐藏视图中首次加载一直等待画面的故障；首次加载失败会保留状态并允许显式重试。
- 未完成初始化的旧世界，可在重新初始化时修复精确识别的旧加载组件，生成新草稿并重新检查。用户改过的组件、已正式采用的世界不会被这一修复覆盖；原始受管源码与存档保留。
- 预览旁显示不能应用的原因与下一步，Godot 游戏画面为提示区域预留空间。
- 游玩支持 F11 全屏切换、Esc 按界面层级退出全屏；不会关闭应用或直接离开世界。
- 每次任务显示实际宿主记录的总 Token、TPS、耗时和执行模型；缺失和部分数据明确标记。左下角版本文字不再触发更新入口。
- 补齐素材目录选择、导入及预览之间的通道，保留目录授权与资源校验。

运行方式仍为原综合客户端。新版本号只用于区分这次预览和旧 0.14.3；PI-Desktop/Godot 等原有许可证与来源声明保留。真实键盘体验、玩家内容复测及独立 Windows 安装环境的未验项目将在交付报告中单独列出。
