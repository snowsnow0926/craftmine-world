# 造物沙盒玩家生命组件

此可选组件作为世界直接子节点使用，`entity_id` 由实例提供，`player_path` 默认 `../Player`。它通过通用 `body.components` 账本保存生命，保留既有沙盒 `body.player` 四字段格式；不把第一人称的 WorldState 或 Inventory 搬入沙盒。

需要玩家控制器提供 `set_movement_lock(owner, blocked)`。死亡锁住移动和跳跃，保留重力、观察及退出界面。锁按组件所有者分别管理；复活、组件移除或节点释放只解除自身的锁。一个玩家只允许一个生命组件，重复配置会使状态验证失败。

`take_damage(amount)` 和 `revive()` 供实际怪物、复活点等源码行为调用，暂停时拒绝。它们不是宿主/模型的直接改生命操作。恢复完整验证后才修改生命并同步移动锁；旧档中没有组件时由候选的新增组件默认值进入已有迁移流程。

`maximum_health` 是源码配置，生命状态必须处于其范围内。若修改最大生命导致旧生命越界，当前拒绝迁移，不能静默清零或丢弃旧进度。

本组件尚未注册到内置包；下一步连接真实武器、怪物和掉落，完成整套沙盒玩法后再发布对应版本。已有宠物包字节与已冻结成品保持不变。
