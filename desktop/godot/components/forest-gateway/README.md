# 林间入口

这是**预先设计好的静态场景**，用于展示和复用已审核素材，不是模型自主创造的结果。

七棵树采用橡树与松树两种轮廓。左右较高前景树、中景石拱门及错落后景树围出入口；草、红花、灌木和石头成簇分布于路径两侧。局部正 Z 为入口一侧，沿负 Z 穿过拱门进入林内。门洞已绕 Y 轴旋转 90 度；原始模型的侧向薄轴不再朝向步行方向。

完整目录按一个普通 scene 包安装到 `res://addons/cw.scene.forest-gateway/`。入口为 `scenes/forest_gateway.tscn`，只有根节点的 `entity_id: String` 身份字段脚本；内部树木保留明确的 Node 路径，后续可以通过普通场景源码修改单棵树。原 GLB、纹理、最小 `.import` 配置及 Kenney CC0 许可字节均复用既有精选素材，不重制成方盒。

靠近入口的路径留出约 2.4 米宽度。门洞底部有原模型的柱脚凸出，按真实胶囊碰撞查询保守声明 1.4 米净通行带：半径 0.3 米、高 1.8 米胶囊沿中心及左右偏移 0.4 米的路线均可通过。拱门和四块石头使用原真实三角碰撞；树木、花草和灌木沿既有素材约定作为可通过装饰，不给树冠套大碰撞盒。

场景不带地面、玩家、世界环境、太阳或输入逻辑。应放在已有可行走平地上；建议另行通过独立 `cw.environment.natural-daylight` 改善地面和日光，避免将世界环境错误绑定到本场景的子节点。根节点原点位于整体实际几何包围盒的底部中心。门洞中心约为局部 `(-0.066, 0, 2.833)`；建议初次查看位置为 `(-0.066, 2, 11.833)`，看向 `(-0.066, 2, 1.833)`。精确数值见 `component.json` 的 `sceneContract`。

`layout.json` 为固定构图清单；生成工具是仓库 `scripts/build-forest-gateway.mjs`，不是运行时能力。headless 加载和几何通道检查只验证兼容与通道，最终构图观感需在真实产品内截图确认。
