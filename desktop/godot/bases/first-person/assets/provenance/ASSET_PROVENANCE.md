# Asset provenance and licence record — first-person base

Every asset in this directory is original work authored for this repository. No
third-party, commercial or ripped game asset is included, downloaded, converted
or referenced. No asset from another game's data files is present.

## Geometry

| File | Origin | Licence |
| --- | --- | --- |
| `assets/meshes/weapon_pistol.obj` | Generated by `tools/generate_meshes.mjs`; vertex data authored in that file | MIT |

| `icon.svg` | Hand-authored SVG in this repository | MIT |

The meshes are axis-aligned box primitives assembled into a low-poly shape. They
carry no scanned data, no photogrammetry, no purchased model and no extracted
geometry. `node tools/generate_meshes.mjs` regenerates them deterministically;
`node tools/generate_meshes.mjs --check` fails if the committed files differ from
the generator.

## Materials and interface resources

`assets/materials/*.tres`, `data/ui/*.tres`, `data/equipment/*.tres`,
`data/quests/*.tres` and `data/balance/*.tres` are hand-written Godot resources
containing only numeric parameters and colour values chosen for this base. No
third-party texture, HDRI, font, sound or shader is used.

## Engine

The base runs on Godot 4.7.2-stable, which is MIT licensed. The engine itself is
not redistributed from this directory; the repository's pinned toolchain and its
licence notices live in `desktop/godot/licenses/`. When this base is packaged for
distribution, those notices must travel with it, and the engine's own
`COPYRIGHT.txt` must be included as required by Godot's licence. See
`docs/GODOT_MULTIBASE_DEVELOPMENT_PLAN.md` section 13 and
`desktop/windows-NOTICES.md`.

## Reuse

The MIT grant in `licenses/ORIGINAL_ASSETS_LICENSE.txt` covers the geometry,
materials and icon in this directory, so a world built from this base may be
copied, modified, re-saved and exported. It does not cover the Godot engine or
any other part of the client, which keep their own licences.

## Verification

The acceptance run records the resolved asset path of the equipped model
(`display.meshPath` must start with `res://assets/meshes/`), so a build that
silently swapped in an external model would be visible in the evidence. This
record is a statement of authorship, not a legal review of the whole client.
